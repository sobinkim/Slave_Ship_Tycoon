# 함대 / 합성 카드 화면

- 함대 화면에서 소환 버튼과 가격 표시를 숨기고 참조를 해제했다. 모집은 하단 메인 메뉴에서만 진입한다.
- 함대: 상단 6칸 편성, 5열 보유 함선 카드 목록, 하단 함선 합성 / 닫기.
- 합성: 별도 전체 화면. 원본→상위 등급 미리보기, 직접 선택하는 재료 3칸, 재료 목록, 합성 / 돌아가기.
- 같은 등급의 미편성 함선만 선택한다. 재료 칸을 누르면 선택 해제. 자동 재료 보충은 하지 않는다.
- 합성 화면만 닫으면 전투 정지를 유지하고, 함대 화면을 닫으면 이전 전투 속도로 복원한다.
- 두 화면 모두 PanelFadeIn의 Duration Seconds(기본 0.24초)로 페이드인 시간을 조절한다. UI 시간은 unscaledDeltaTime을 사용한다.

## 변경 파일

- SampleScene.unity: 카드 배치, 별도 합성 화면, 연결과 페이드 컴포넌트.
- EscortInventoryItem.prefab / EscortInventoryItemView.cs: 카드 모양, 등급색, 한글 등급과 수량, 재료 선택 상태.
- FleetMergeScreen.cs: 재료 선택/해제/미리보기/합성/돌아가기.
- PanelFadeIn.cs: 전투 정지 중에도 진행되는 페이드인.
- PlayerFleetPanelController.cs: 합성 화면 진입.
- PlayerFleetManager.cs: 지정한 재료 3척 검증 후 합성하는 API. 기존 합성 API 유지.
- FleetCardLayoutSetup.cs: 초기 적용용 Editor 유틸리티. 재실행 시 배치값을 덮어쓰므로 커스텀 후 반복 실행하지 않는다.

## 검증

- 컴파일 성공, 씬 재로드 후 실제 Play 모드 확인.
- Time.timeScale=0에서 함대 및 합성 화면 alpha가 0에서 1로 변화.
- 재료 3개 선택 후 합성 활성화, 재료 해제 시 비활성화.
- 3척 소모/1척 지급으로 전체 보유 수 -2, 재클릭 추가 소모 0.
- 합성 닫기 후 timeScale 0, 함대 닫기 후 1 복원 확인.
- 테스트 구간 새 콘솔 오류 없음. 1080x1920 시각 검증. 다른 비율/노치 기기는 미검증.
- 동일 함선은 종류별 카드 하나와 수량으로 표시한다. 보유 종류가 적으면 격자에 빈 공간이 생긴다.
