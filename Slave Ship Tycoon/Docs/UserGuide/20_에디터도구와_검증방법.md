# 에디터 도구와 검증 방법

## 반복 제작 도구와 초기 적용 도구

현재 프로젝트에는 매번 콘텐츠 편집에 사용할 도구와 과거 UI·씬 구성을 한 번 적용하기 위해 만든 도구가 함께 있습니다. 이름에 Setup이 붙었다고 모든 새 함선을 자동 설정해 주는 도구는 아닙니다.

| 도구 | 용도 | 사용 전 확인 |
|---|---|---|
| SB > Stage Enemies > Layout Editor | 12칸 웨이브 작성/저장 | Chapter/Stage/Database, 기존 덮어쓰기 |
| StageSpawnManagerEditor | Inspector/Scene 슬롯 설명·라벨 | 실제 연결된 Spawn Points |
| SB > Stage Enemies > Create Test Content | 테스트 적·데이터 생성 | 일반 양산에 사용하지 않기 |
| Tools/SB/Run Targeting Regression Tests | ShipTargetingTests 실행 | 전체 테스트 실행과 구분 |
| Tools/Fleet/Set Up Shield Effects | 기존 방패 구성 적용 | 기존 프리팹·설정 변경 범위 |
| Tools/SB/Build Main Ship Upgrade UI | 강화 UI 구성 | 기존 UI 덮어쓰기 여부 |
| Tools/SB/Apply Korean UI | 한국어 UI 적용 | 현재 문구·폰트 커스텀 여부 |

CommanderPanelSetup/ScrollSetup/CardShapeSetup, FleetCardLayoutSetup/MergeResultSetup, HarborUiSetup/UxSceneSetup/CombatPresentationSetup, HudBalanceSetup, LargeControlSetup는 각각 과거 화면 배치와 표시 구성을 적용하는 코드입니다. 일부는 메뉴가 아니라 Apply 메서드를 가진 유틸리티입니다. 새로운 콘텐츠 제작 때 일괄 재실행하지 말고 대상 경로·수치·저장 코드를 먼저 읽으세요.

## 기능 변경 후 공통 확인

1. 변경 프리팹·데이터·씬을 저장하고 컴파일 완료를 기다립니다.
2. Console의 첫 오류부터 확인합니다. 변경 이전 오류와 새 오류를 구분합니다.
3. 새 콘텐츠 한 개로 최소 구성 전투를 확인합니다.
4. 정상 실행뿐 아니라 사망·비활성·전투 종료를 확인합니다.
5. 다음 전투에서 풀 재사용 상태가 복원되는지 확인합니다.
6. 실제 UI 경로로 모집/편성/강화/정산을 확인합니다.
7. 최종 화면 비율과 실제 모바일 사용을 별도로 확인합니다.

## 기존 테스트

Unity Test Runner의 EditMode에서 필요한 테스트를 선택합니다. 재생 중 테스트 실행은 현재 플레이를 중단할 수 있으니 작업 중 게임 상태를 먼저 정리하세요.

| 테스트 | 확인 내용 |
|---|---|
| StageEnemyLayoutTests | 기존 9칸 호환, 네 번째 행 |
| ShipTargetingTests | 비활성·사망 제외, 발사 시점 재선택, 풀 세대 |
| CrusherTargetingTests | 현재 체력 비교, 동률 거리, 명령 우선 |
| ProjectileEvasionTests | 운 확률, 미스 착탄, 경고/풀 정리 |
| FleetMergeAllTests | 미편성 재료, 연속 등급 합성, 반복 실행 |

테스트 코드가 존재하는 것과 최신 변경에서 통과했다는 것은 다릅니다. 이 설명서 작성에서는 게임 코드를 변경하지 않았으며 위 테스트를 새로 실행하지 않았습니다.

## QA 자료 읽기

QA의 날짜별 문서는 해당 시점의 구현·검증 기록입니다. 특히 과거 테스트 수치/모집 확률/임시 재화·제거된 효과는 현재 설정으로 단정하지 마세요. 최종 상태는 현재 에셋/코드를 확인합니다.

ArtBackups는 이전 그림·프리팹·씬을 보관합니다. 전체 씬을 오래된 파일로 덮으면 이후 작업이 사라질 수 있으므로 필요한 항목만 선택적으로 복구합니다. `Assets/QA`는 화면 미리보기, 루트 QA의 C# 파일은 일회성 검증/세팅 스크립트일 수 있으며 게임 런타임 코드와 구분합니다.

## 아트·재질 변경 확인

ShipWaterline은 선체 수면/침몰, FleetShield는 방패, FleetStatusIcon은 아이콘 색/알파, CrusherStakeAura는 코팅을 그립니다. 머티리얼을 복제하면 새 그림에만 적용할 수 있지만 Animator의 머티리얼 속성 트랙도 확인해야 합니다.

이미지 교체 뒤 Texture Type=Sprite, Sprite Mode, PPU, Filter Mode, 압축, Mipmap, Alpha, Sprite Rect/Pivot을 확인합니다. 특정 전체 UV를 사용하는 파쇄탄 효과는 SpriteAtlas 패킹과 호환된다고 가정하지 않습니다. 기존 아트의 이미지 생성 프롬프트는 관련 QA/Docs 기록에서 찾을 수 있습니다.

## 문서 검증 범위
