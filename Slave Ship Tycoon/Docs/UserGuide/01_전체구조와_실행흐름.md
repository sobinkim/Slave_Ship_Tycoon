# 전체 구조와 실행 흐름

## 게임을 이해하는 네 가지 층

| 층 | 예 | 담당 역할 |
|---|---|---|
| 콘텐츠 설정 | ChapterContainer, EscortShipData, 스킬 에셋 | 어떤 콘텐츠를 사용할지 결정 |
| 실제 게임 상태 | GameFlowManager, PlayerFleetManager, CargoManager | 현재 챕터·보유함·화물 관리 |
| 현장 오브젝트 | Ship, Enemy, 발사체 | 실제 공격·피해·이동·사망 처리 |
| 화면 표시 | Controller/Presenter, View, 선체 연출 | 숫자·버튼·그림을 보여줌 |

예를 들어 모집 카드의 그림을 바꿀 때는 EscortShipData의 Icon을 수정합니다. 실제 바다에 뜨는 함선 그림은 해당 ShipPrefab의 Visual을 수정합니다. 같은 함선이라도 두 설정은 별도입니다.

## 주요 폴더

- `Assets/Runtime/Core`: Entity, 체력, 스탯, 애니메이션, 상태머신 공통 기반.
- `Assets/Runtime/EventBus`: 시스템 사이의 이벤트 전달.
- `Assets/SB/Scripts`: 현재 게임의 기능 코드. Stage/Fleet/Commander/Ship/UI 등으로 분리되어 있습니다.
- `Assets/SB/Prefabs`: 아군, 적, 탄, 이펙트, UI 설계도.
- `Assets/SB/Data`: 챕터·웨이브·함선 목록·스킬·장비 설정.
- `Assets/SB/SO`: 스탯 종류, 화물과 처치 보상 설정.
- `Assets/SB/Animations`, `Assets/SB/Art`: 움직임, 그림, 재질, 셰이더.
- `Assets/SB/Editor`: Unity 제작 도구와 테스트.
- `QA`: 작업 기록·미리보기·일회성 검증 자료·백업.

## 출항부터 다음 전투까지

```text
GameFlowManager.StartStage()
  → 현재 챕터에서 사용할 웨이브 선택
  → StageStartedEvent
  → StageSpawnManager가 아군·적 생성/재사용
  → StageBattleInitializedEvent
  → StageEncounterDirector가 적 함대 접근 연출
  → BattleStartEvent
  → 타겟 선택·공격·피해·보호·지휘 스킬
  → 전투 종료 → StageBattleEndedEvent
  → 클리어/실패 처리 → 다음 전투 또는 챕터 전환
```

`BattleManager`는 전투 참가자와 승패를 다루고, `GameFlowManager`는 이후 진행할 챕터·스테이지를 결정합니다. `StageSpawnManager`는 데이터와 스폰 지점을 연결합니다. 이 세 역할을 한 곳에 섞어서 수정하지 않는 것이 구조를 이해하기 쉽습니다.

## Obtain과 Sell

Obtain 챕터에서는 Stages 안의 웨이브를 랜덤 선택하여 반복합니다. 보스를 별도 도전하고 이기면 다음 챕터로 이동합니다. Sell 챕터에서는 Stages 배열의 순서대로 진행하고 마지막 구간을 클리어하면 판매 정산 후 다음 챕터로 넘어갑니다.

현재 진행은 ChapterContainer의 Route Type을 읽습니다. 새 챕터 생성 도구가 홀수=Obtain/짝수=Sell 기본값을 넣더라도, 제작자가 Inspector에서 실제 값을 확인해야 합니다.

## 기본 씬에서 연결 확인하기

1. SampleScene을 엽니다.
2. StageSpawnManager가 있는 오브젝트를 선택합니다.
3. Chapter Database, Player Fleet Loadout, Player Fleet Manager, Upgrade Provider, Cargo Manager, Stage Encounter Director를 확인합니다.
4. 본선 Spawn Point 1개, 호위선 6개, 적 12개를 확인합니다.
5. StageEncounterDirector의 Enemy Fleet Root와 Destination을 확인합니다.
6. 함대·재화·강화·지휘·판매 관리자와 각 UI Controller의 참조를 확인합니다.

문서 작성 당시 실행 중 씬에서 StageSpawnManager의 적 12개/호위 6개 배열과 위 주요 참조, StageEncounterDirector의 EnemySpawnPoints/EnemyStopPoint 연결을 확인했습니다. 실행 상태 확인이며 모든 기능의 성공을 의미하지는 않습니다.

## 설정이 저장되는 곳

프리팹 설정은 해당 프리팹 파일에, 챕터 설정은 데이터 에셋에, 관리자 참조는 씬에 저장합니다. 보유 수량·재화·편성의 실행 상태는 영구 저장 기능과 별개입니다. 현재 코드에서 완성된 저장/불러오기 시스템을 확인하지 못했으므로 Play 종료 뒤 유지되는 것으로 가정하지 마세요.

문제가 생기면 콘솔의 첫 오류를 확인한 뒤, 해당 데이터 → 관리자 참조 → 현장 프리팹 → 화면 표시 순으로 좁혀 보세요. 예를 들어 웨이브가 안 뜨면 UI보다 ChapterContainer와 Spawn Points를 먼저 확인합니다.
