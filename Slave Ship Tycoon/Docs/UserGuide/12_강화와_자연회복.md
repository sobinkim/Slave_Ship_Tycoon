# 강화와 자연회복

## 강화 구조

ShipUpgradeManager가 강화 수준·비용·증가량과 전체 함대 강화값을 관리합니다. PlayerFleetUpgradeProvider는 그 값을 전투 함선에 제공합니다. MainShip은 UpgradeEvent를 받아 본선 스탯과 지휘 스탯을 갱신합니다. 화면은 MainShipUpgradePresenter/View/SlotView가 담당합니다.

## 설정 위치

씬 ShipUpgradeManager의 **Upgrade Growth Datas**를 펼칩니다. 현재 강화 종류는 Health, AttackPowerPercent, AttackSpeedPercent, CargoCapacity, Luck, CommanderGaugeMax, CommanderGaugeRecoveryPerSecond, HealthRecoveryPerSecond입니다.

| 항목별 필드 | 의미 |
|---|---|
| Upgrade Type | 어떤 능력을 강화할지 |
| Currency Type | 소모 재화 |
| Level | 시작 수준 |
| Current Cost | 이번 구매 비용(long) |
| Cost Growth Rate | 다음 비용의 배수 |
| Increase Value | 이번 구매 증가량 |
| Increase Growth Rate | 다음 증가량의 배수 |

예: Current Cost=100, Cost Growth Rate=1.15, Increase Value=2, Increase Growth Rate=1이면 다음 비용은 115, 증가량은 계속 2입니다. 예시 값이며 현재 씬 값은 직접 확인합니다.

Main Ship Upgrade Data는 현재/시작 함대 값입니다. 성장표를 수정하는 것과 기본 능력값을 수정하는 것은 다릅니다. 비용과 증가량만 바꾸고 기존 능력값이 바뀌었다고 가정하지 마세요.

## 구매 순서

TryUpgrade → 종류별 성장표 확인 → 비용 유효성 검사 → CurrencyManager 차감 → 수준 증가 → 능력 증가 → 다음 비용/증가량 계산 → UpgradeEvent 순입니다. 비용이 0 이하이거나 재화가 부족하면 실패합니다.

공격력·공속은 퍼센트 숫자입니다. 25는 25%를 의미합니다. 체력·용량·게이지·초당 회복은 각 항목의 절대 단위입니다. Provider가 적용되는 아군과 적용되지 않는 적을 구분하세요. 운송선은 일반 피해를 받지 않는 별도 규칙을 사용하므로 본선 HP 강화가 일반 체력 패배를 만들지는 않습니다.

## 자연회복

PlayerFleetRecovery의 Stage Spawn Manager와 Recovery Delay After Damage Seconds를 설정합니다. 회복량은 함선 HealthRecoveryPerSecond 스탯 + 함대 회복 강화입니다. 마지막 피해 이후 설정한 게임 시간만큼 지난 부분부터 회복합니다. 다시 피해를 받으면 지연이 갱신됩니다.

전투 중과 클리어 후 회복이 가능하고, 살아 있는 활성 함선을 대상으로 합니다. 사망한 함선이 자연회복 틱만으로 즉시 부활하는 구조는 아닙니다. 다음 전투 준비의 PrepareForNextBattle과 재스폰 흐름에서 상태를 따로 처리합니다.

클리어한 다음 웨이브에서는 같은 함선과 현재 HP를 유지하는 경로가 있습니다. 매 전투 시작마다 모든 살아 있는 함선을 무조건 최대 HP로 바꾸는 설정으로 이해하지 마세요. 실패 후 재시도는 함대 전체 리셋 경로가 따로 있습니다.

## 설정 예시와 검증

회복 지연 2초, 기본 회복 3HP/초, 강화 회복 2HP/초라면 피해 후 2초가 지난 뒤 5HP/초 회복합니다. Time.timeScale=0인 함대 화면에서는 게임 시간이 흐르지 않습니다.

강화 전/후 비용·재화·최종 피해·공속을 확인하세요. 회복은 피해 직후, 지연 직전/직후, 반복 피격, 전투 종료, 다음 웨이브를 비교합니다. UI 수치만 바뀌면 StageSpawnManager의 Player Fleet Upgrade Provider와 ShipCombatStatCompo 연결을 확인합니다.

관련 파일: ShipUpgradeManager, PlayerFleetUpgradeProvider, PlayerFleetRecovery, ShipCombatStatCompo, MainShip, EntityHealth.
