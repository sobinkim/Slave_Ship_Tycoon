# 배경·패럴랙스·함선 물살

## 배경 구조

하늘·섬·바다·전경 파도 레이어가 여러 Sprite 타일로 이어집니다. ParallaxLayer가 왼쪽으로 이동시키고 경계 밖 타일을 오른쪽 끝으로 재배치합니다. 레이어마다 속도를 다르게 설정하면 거리감이 생깁니다.

그림은 `Assets/SB/Art/Sprites/Background/Parallax`를 확인합니다. 씬 BackgroundRoot 아래 실제 레이어의 ParallaxLayer를 선택하세요. 달 MistMoon은 별도 고정 오브젝트이므로 반복 타일에 자동으로 포함되지 않습니다.

## 레이어 설정

| 필드 | 의미 |
|---|---|
| Sprites | 이동·재배치할 타일 Transform 배열 |
| Scroll Speed | 왼쪽 이동 속도 |
| Sprite Width | 반복 배치 간격, 그림 픽셀 폭 자체가 아님 |
| Left Reset X | 타일 재배치 기준 월드 X |
| Dont Care | 스크롤 중지 요청을 무시하고 계속 이동 |
| Alternate Mirrored Tiles | 재배치 타일을 오른쪽 끝 타일과 반대 Flip X로 연결 |

현재 구현은 이동과 경계 비교에 **월드 좌표**를 사용합니다. 부모 스케일을 바꾸면 타일의 실제 폭도 바뀌므로 Sprite Width와 경계도 함께 점검해야 합니다.

## 새 배경 교체

1. 새 Sprite의 실제 월드 폭을 확인합니다. 픽셀 폭/PPU에 스케일이 반영됩니다.
2. 기존 레이어 타일들의 Sprite를 교체합니다.
3. 같은 레이어 타일의 Y·Scale을 맞춥니다.
4. Sprite Width에 반복 간격을 넣고 초기 X 간격도 맞춥니다.
5. 미러링을 쓰면 첫 타일들을 정방향/반전/정방향처럼 교대로 설정합니다.
6. Left Reset X가 화면 왼쪽 밖인지 확인합니다.
7. 충분히 스크롤시켜 타일이 여러 번 순환해도 이음새와 반전이 유지되는지 봅니다.

기존 작업의 폭 16.56/반복 간격 16.52 같은 숫자는 특정 그림과 PPU에 맞춘 기록입니다. 다른 이미지를 넣을 때 그대로 유지할 값은 아닙니다. 미세 겹침으로 틈을 줄일 수 있지만 반복 그림 자체가 자연스럽게 연결되는지도 확인해야 합니다.

## 표시/이동 이벤트

ParallaxLayerManager는 조우 시작/중지 이벤트에 따라 자식 레이어를 움직입니다. ParallaxAlphaController는 Visible Alpha/Hidden Alpha/Fade In Speed/Fade Out Speed/Hide On Awake와 Renderer 배열로 표시 강도를 조절합니다. 이동 속도와 페이드 속도는 별도입니다.

## 함선 물살

해적·운송 해역 모두 함선 프리팹의 ShipWakeEffect를 공통으로 사용합니다. Owner, Ship Animator, Wake Renderer를 사용하고 Move Parameter를 읽어 표시합니다. 이동/조우 중 물살이 나타나고 정지 전투에서는 사라집니다.

해적 해역의 SeaCreatureSurvivalDirector는 전투 참조 초기화 후 함선을 Move로 전환하고, 크리쳐와 조우하면 Idle로 전환합니다. 전멸 후 다음 항해에서도 같은 이동 상태와 물살을 재사용합니다. 기존 별도 선 기반 항적·수면 흐름 컴포넌트와 VoyageMotion 오브젝트는 제거했습니다. SeaVoyageMotor는 함대·카메라·배경의 실제 전진을 담당하므로 유지합니다.

프리팹의 `Presentation/ShipWaterWake` Transform으로 위치·크기를 맞춥니다. Fade In/Out Seconds, Foam Color, Ripple Cycles Per Second, Ripple Scale/Opacity Amount로 기본 물살을 조절합니다.

추가 포말은 Trailing Foam 배열에 SpriteRenderer를 직접 연결하고 Foam Cycle Seconds, Foam Start Local Position, Foam Travel Local Offset, Foam Start/End Local Scale, Trailing Foam Opacity로 움직임을 정합니다. 오른쪽 진행 함선의 뒤로 흐르는 포말은 보통 X 이동량을 음수로 사용합니다. 새 자식을 만들어도 배열에 연결하지 않으면 자동으로 참여하지 않습니다.

2026-10-23부터 함선 이동 물살은 함선의 굵은 외곽선 대신 **바다의 가늘고 끊어진 물결 스타일**을 사용합니다. 넓은 포말 그림을 반복하지 않고 선수 양옆의 좁은 곡선과 뒤로 흘러가는 독립 잔물결을 셰이더로 그립니다. `ShipWaterContactQuad`를 Sliced로 사용하며 기존 Renderer Size와 Transform 크기를 유지합니다. 크리쳐의 기존 물살은 변경하지 않았습니다.

- 낮 재질: `Assets/SB/Art/Materials/Sea/ShipSailingWake.mat`
- 밤 재질: `Assets/SB/Content/Bounty/Materials/NightWake.mat` (같은 셰이더, BountyNightEnvironment의 Wake Tint로 밤 밝기 적용)
- 셰이더: `Assets/SB/Art/Shaders/PursuitWake.shader` (`Fleet/Pursuit Wake`)
- 재질 Inspector의 **Water Crest / Broken Foam**은 색, **Wake Opacity**는 전체 강도, **Crest Thickness**는 선 굵기, **Crest Breakup**은 포말의 끊김 정도입니다.
- 수면 잠김 적용 후 이동 물살이 약하다는 피드백으로, 낮·밤 재질의 **Wake Opacity 0.9 / Crest Thickness 0.032 / Crest Breakup 0.4**로 조절했습니다(이전 0.7 / 0.018 / 0.65). Water Crest는 `(0.55, 0.80, 0.82)`, Broken Foam은 `(0.78, 0.91, 0.91)`입니다. 선을 굵고 조금 더 연속적으로 만들어 선수의 물 갈라짐과 뒤쪽 잔물결을 강조합니다. 이동 화면 전후 비교와 밤 추적전 화면을 확인했으며 추가 Inspector 연결은 없습니다. 적용 도구는 `AgentScripts/StrengthenShipWake.cs`, 기존 물살 제작 도구의 재질 기본값에도 반영했습니다.
- 이동 시간·선수/잔물결 구분·조각별 위상은 ShipWakeEffect의 PropertyBlock으로 전달합니다. 기존 PropertyBlock을 보존하고 공유 재질을 런타임에 복제하거나 변경하지 않습니다. 일시정지 시 물결도 멈춥니다.
- Editor 적용 도구: `AgentScripts/SeaStyleShipWake.cs`. `Apply`는 함선 물살만 교체하고 반복 실행해도 크기를 누적 변경하지 않습니다. Unity가 Simple→Sliced 전환 시 Transform을 바꾸므로 도구에서 원래 Scale을 보존합니다.

## 함선이 수면에 잠기는 경계

2026-10-23부터 `ShipWaterContact`가 선체 잠김과 접촉 잔물결을 함께 담당합니다. 아군·일반 적·추적 적의 함선 셰이더 사용 프리팹 22개에 선체 참조와 수면 높이를 명시적으로 연결했습니다. 일반 항해에 침몰용 `_Waterline`을 그대로 사용하면 수습 포격선 선체가 중간에서 잘리므로, 평상시 수면은 별도로 지정합니다.

- `Hull Renderer`: 실제 선체 Visual의 SpriteRenderer입니다. 돛 문양·발사체·체력바는 연결하지 않습니다.
- `Surface Local Y`: Ship 원점 기준 수면 높이입니다. 값을 높이면 선체가 더 깊이 잠깁니다. 각 그림의 바닥·스케일·피벗을 보고 조절하고, 접촉 Renderer와 물살의 높이도 함께 맞춥니다.
- `Contact Tint Depth`(기본 0.055): 수면 위쪽에 물빛이 번지는 월드 거리입니다.
- `Edge Fade Depth`(0.025): 수면 아래 선체가 부드럽게 사라지는 월드 거리입니다.
- `Surface Wave Height`(0.008): 수면 경계의 작은 요철 높이입니다.
- `Water Tint`: 접촉부 물빛과 혼합 강도입니다. 낮/밤 주변광은 기존 `_EnvironmentTint`에 의해 함께 적용됩니다.

수면은 함선의 부유·기울기 적용 후 갱신해 수평을 유지합니다. 다른 셰이더 속성을 보존하는 MaterialPropertyBlock을 사용하며, 선체·포구 Transform이나 카메라를 옮기지 않습니다. 주간 접촉 그림자 강도는 0.18로 낮추고 잔물결·이동 물살을 동일 수면에 정렬했습니다. 사망 시 기존 `_SinkProgress` 변위도 이 수면 아래로 가려집니다.

최초 배치 도구는 `AgentScripts/RefineShipSubmersion.cs`의 `Apply`입니다. 실행 시 기존 수면 높이와 물살 Y를 다시 기록하므로, Inspector에서 수동 조절한 뒤에는 전체 재적용하지 않습니다. 런타임에 이미지 탐색이나 수면 자동 보정은 하지 않습니다. 일반 함선은 그림 바닥에서 0.065, 본선·메인 해적선은 0.09 월드 거리 위를 최초 수면으로 잡았습니다.

낮 일반 전투와 밤 추적전의 실제 재생 화면을 확인했습니다. 기록: `Assets/Artifacts/BountyPursuit/14-Hull-Waterline-Day.png`, `15-Hull-Waterline-Night.png`. 컴파일·셰이더 메시지는 정상이며, 기존 장비 아이콘 누락(`MerchantLedger needs an icon.`)과 재생 종료 시 `SeaVoyageMotor.SetDistance`의 파괴된 Transform 오류는 별도입니다.

## 현재 사용하지 않는 바다 셰이더

QA/CasualSeaShader.md에는 사용자 요청으로 제거한 바다 셰이더 기록이 있습니다. 그 설정을 현재 활성 효과로 안내하지 않습니다. 현재 재질은 실제 씬 Renderer에서 확인하고 백업은 필요한 항목만 선택적으로 복구하세요.

## 검증

타일 틈·잘못된 반전·겹침·달 위치를 긴 스크롤에서 확인합니다. 물살은 이동→정지→재이동과 풀 재사용을 확인합니다. Game View 세로 비율과 실제 모바일 성능/터치 검증은 별개입니다.
