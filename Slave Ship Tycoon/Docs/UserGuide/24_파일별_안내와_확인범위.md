# 파일별 안내와 확인 범위

기준일: 2026-10-02. 아래 색인은 현재 프로젝트의 게임/공통 코드와 제작 도구를 빠짐없이 찾아가기 위한 목록입니다. 각 스크립트마다 독립 사용법이 있는 것은 아니므로 기능별 설명서로 연결했습니다. 작성자가 AI인지 사람인지 확정하는 목록은 아닙니다.

## 이번에 확인한 내용

- Unity 6000.0.59f2, 현재 Editor 재생 중. 컴파일 실패 플래그 없음. 게임·씬·프리팹 설정을 변경하지 않고 문서만 추가했습니다.
- 실행 씬 StageSpawnManager: 본선/함대/강화/화물/챕터/조우 참조, 호위 스폰 배열 6개와 적 12개 확인. 적 지점은 EnemySpawnPoints, 호위 지점은 EscortShipSpawnPoints 아래에 연결되어 있습니다.
- StageEncounterDirector의 Enemy Fleet Root=EnemySpawnPoints, Destination=EnemyStopPoint 확인. 과거 기록의 참조 누락 상태와 현재 실행 상태를 구분했습니다.
- 현재 Console에 MerchantLedger needs an icon. 오류가 있습니다. TransportEquipmentItemData.Icon 누락을 확인할 항목이며 이번 문서 변경의 컴파일 오류가 아닙니다. 14번 안내에 연결 방법을 설명했습니다.
- 문서 25개의 내부 링크 231개와 코드/에셋 경로 276개의 존재 여부를 확인했고 누락은 없었습니다. 기능 테스트, 전투 시뮬레이션, 모바일 검증은 이번 문서 작업에서 새로 실행하지 않았습니다.
