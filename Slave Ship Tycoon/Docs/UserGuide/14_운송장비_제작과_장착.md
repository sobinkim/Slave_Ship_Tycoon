# 운송 장비 제작과 장착

운송 장비는 판매 정산 보상을 바꾸는 데이터입니다. 현재 전투 무기를 장착하는 시스템과 다르며, TransportEquipmentManager가 보유/장착/운송 시작 스냅샷을 관리합니다.

## 새 장비 제작

1. `Create > SB > Transport Equipment > Item` 또는 기존 장비 Duplicate를 사용합니다.
2. `Assets/SB/Data/TransportEquipment`에 저장합니다.
3. Item Id를 유일하게 지정하고 Display Name/Icon/Grade를 채웁니다. 아이콘은 검증 필수입니다.
4. Settlement Modifiers에 원하는 재화와 효과를 넣습니다.
5. 씬 TransportEquipmentManager의 Owned Items에 추가합니다.
6. 시작 장착을 원하면 Initial Equipment에 연결합니다.
7. 장비 화면 Controller/View의 항목 생성·아이콘·선택 표시를 확인합니다.

기존 MerchantLedger, CommandOrders, ShipBlueprint, MixedManifest는 설정 예시로 볼 수 있습니다. 실제 수치는 해당 에셋 Inspector에서 확인하세요.

## 보상 수정 필드

| 필드 | 의미 |
|---|---|
| Currency Type | 수정할 재화 |
| Modifier Type=FlatReward | 고정량 추가 |
| Flat Amount | 추가할 양 |
| Modifier Type=RewardMultiplier | 보상 배율 |
| Multiplier | 1=유지, 1.5=1.5배 |

동일 장비에 같은 재화·같은 Modifier Type을 중복 넣으면 첫 항목만 사용하는 검증 경로가 있습니다. 같은 재화의 고정 보상과 배율은 종류가 서로 다르므로 구분해 설정할 수 있습니다. 계산은 **배율 먼저, 고정량 추가 나중**입니다. 소수점은 내림합니다. 예: 1000에 1.5배와 +100이면 1600입니다. 배율은 기본 정산에 존재하는 재화에 적용하고, 고정 추가는 없는 재화도 추가할 수 있습니다.

## 장착과 스냅샷

TryEquip은 보유 장비인지와 설정이 유효한지 확인합니다. Sell 챕터가 시작될 때 현재 장착 장비와 효과 숫자를 복사해 스냅샷으로 저장합니다. 정산은 이 복사본을 사용하므로 운송 도중 데이터나 화면 선택이 바뀌어도 그 출항의 기준을 뒤늦게 변경하는 것으로 가정하지 마세요.

현재 TryEquip은 보유 여부·설정·ID 중복 등을 검사하며 운송 중 교체 자체를 금지하는 조건은 없습니다. 교체해도 현재 출항의 스냅샷에는 반영되지 않고 다음 Sell 진입 때 사용됩니다. 보유 목록은 Inspector 초기 설정 기반이며, 완성된 장비 획득 상점/드롭/영구 저장이 자동으로 제공되지는 않습니다.

## 사용 예시

Gold 기본 정산이 1000인 출항에서 Gold RewardMultiplier=1.5 장비를 사용하면 배율 단독 효과는 1500을 목표로 검증할 수 있습니다. Emerald FlatReward=10은 해당 재화에 고정 추가를 설정하는 예입니다. 이 값들은 설명 예시입니다.

## 문제 해결

아이콘 누락은 TransportEquipmentItemData.TryValidate에서 오류입니다. Item Id/Display Name/Icon을 먼저 채우세요. 목록에 안 보이면 Owned Items와 UI Controller를, 선택했는데 정산에 안 반영되면 Sell 진입 당시 스냅샷과 SalesManager의 Transport Equipment Manager 참조를 확인합니다.

관련 파일: TransportEquipmentItemData, TransportSettlementModifier, TransportEquipmentSnapshot, TransportEquipmentManager, TransportEquipmentPanelController/View/ItemButtonView.
