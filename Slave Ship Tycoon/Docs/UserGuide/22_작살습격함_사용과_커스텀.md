# 작살 습격함 사용과 커스텀

## 주요 파일

- 함선: `Assets/SB/Prefabs/PlayerShips/HarpoonRaider.prefab`
- 데이터: `Assets/SB/Data/PlayerFleet/HarpoonRaider.asset`
- 실제 작살: `Assets/SB/Prefabs/Projectiles/RaiderHarpoon.prefab`
- 선체 그림: `Assets/SB/Art/Sprites/Ships/HarpoonRaider_Unloaded.png`
- 카드 그림: `Assets/SB/Art/Sprites/Ships/HarpoonRaider.png`
- 기록: `Assets/SB/Docs/HarpoonRaider.md`

## 공격 규칙

후열 → 중열 → 전열 순으로 후보를 찾습니다. Ship.Can Target Protected Ships를 켠 구성으로 보호 중인 후열을 직접 목표로 삼을 수 있습니다. 보호의 피해 감소는 계속 적용됩니다. 뒤 칸 공격과 순간이동/관통/다중 피해를 같은 기능으로 해석하지 마세요.

## 장전 그림과 실제 탄

전투 선체는 작살이 빠진 그림이고 Visual/LoadedHarpoon이 장전 작살을 별도로 보여줍니다. Attack 클립에서 장전 이동 → AttackStart 순간 숨김 → 실제 작살 비행 → 다음 공격에서 복원을 맞춥니다. 카드용 완성 그림을 전투 선체로 바꾸면 선체에 붙어 있는 작살과 LoadedHarpoon이 겹칠 수 있습니다.

작살 크기는 RaiderHarpoon 프리팹 Scale, 장전 모양은 LoadedHarpoon Transform/클립, 발사 위치는 ShootPos/Fire Points에서 각각 맞춥니다. 세 부분의 방향·크기·위치가 발사 순간 자연스럽게 이어지는지 봅니다.

## 경로와 목표 표식

ProjectilePathDisplay는 실제 지나온 위치를 LineRenderer로 보여줍니다. Point Spacing Units, Width Units, Path Color, Sorting Order Offset으로 모양을 조절합니다. 전체 예상 포물선을 미리 그리는 표시와 다릅니다.

공격자의 RaidTargetingIndicator에는 Owner/Attack, 목표 함선의 RaidTargetMarker에는 Ship/Hull/Hook Icon을 연결합니다. 여러 습격함이 같은 목표를 잡아도 갈고리 표식은 한 개를 공유합니다. 표식 위치는 목표의 WorldUI/RaidTargetHook Transform에서 조절합니다.

## 새 습격함 만들기

프리팹·데이터·전용 Controller/클립·필요한 탄을 복제합니다. 고유 ID, 아이콘, 수치, 후열 규칙을 설정하고 장전 그림을 새 탄과 맞춥니다. 실제 공격자 Indicator와 새 적의 Marker를 확인한 뒤 카탈로그/가챠에 등록합니다.

기존 기록의 “모집 확률 50%”는 당시 Weight 합계 기준입니다. 현재 확률은 현재 EscortGachaTable 전체 합으로 계산해야 합니다.

## 검증

전열 적이 살아 있어도 후열 선택, 보호된 후열 선택, 동일 목표 여러 공격자, 표적 사망/교체, 장전 숨김, 작살 경로 정리, 공격자 사망, 다음 출항을 확인합니다. 일반탄까지 경로 선이 생기면 다른 탄 프리팹에 PathDisplay가 잘못 연결되어 있는지 봅니다.
