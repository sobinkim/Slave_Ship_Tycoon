# UI 화면 구조와 연결 방법

## 읽는 방법

현재 메인 화면·적재·함대·모집·합성·정산은 UI Toolkit입니다. UXML은 구조, USS는 모양, C#은 기존 Manager와의 연결을 담당합니다. 가격·소유량·강화·전투 판정은 Manager에서 바꿉니다.

- 함대·모집·합성 작업: [현행 함대 Toolkit 안내](../AI/UI_Fleet_Recruitment.md).
- 인게임·적재·강화·지휘·정산 작업: [현행 인게임 Toolkit 안내](../AI/UI_InGame_Cargo.md).
- 사용하지 않는 구형 화물/운송 장비 패널과 월드 HP/피해 표시는 기존 구조를 보관하고 있습니다.

| 화면 | 연결 담당 | 모양 편집 |
| --- | --- | --- |

## 공통 패널 연결

새 하단 메뉴는 PannelManager를 직접 호출합니다. PanelChanged가 강화 영역을 표시하고 모집을 닫습니다. 기존 PannelManager는 Canvas/GameFrame/PannelButtons에 남아 있으며 자식 uGUI 버튼은 비활성입니다. 기존 UpgradePanelButton.PanelView의 Panel은 비워 두었고, FleetPanelButton.PanelView의 Panel은 FleetToolkitUI/FleetScreen을 가리킵니다.

모집은 RecruitmentToolkitScreen.Open/Close로 열고 닫습니다. OpenStateChanged는 새 하단 메뉴의 선택 표시를 갱신합니다. 보스 버튼은 CargoToolkitScreen.Open, 적재 확인은 GameFlowManager.StartBossBattle로 이어집니다. 같은 동작을 UnityEvent와 코드 양쪽에 중복 연결하지 않습니다.

## 조절 항목

- 색상: Shared/Styles/HarborTheme.uss의 역할별 토큰.
- 화면 배치: 해당 기능의 USS. UXML은 UI Builder에서 편집합니다.
- 강화 행: UpgradeToolkitPanel.Upgrade Rows의 종류/이름/순서. Currency Manager는 재화 부족 상태를 표시합니다. 오른쪽 강화 버튼에서만 실행하며 반복 간격·피드백 시간도 Inspector에서 조절합니다.
- 지휘: 기존 CommanderSkillManager의 Skill Database에 스킬 종류를 등록하고 Loadout에서 초기 슬롯 수/장착을 설정합니다. 별도 스킬 탭에서 슬롯 선택 → 스킬 선택 → 장착하며, UI용 중복 목록은 없습니다. 전투 아이콘 줄 오른쪽 위 AUTO는 기존 자동 사용 설정입니다.
- 재화바: InGameScreen.uss의 64px 한 줄 배치, InGameToolkitScreen.Currency Slots의 Sprite/틴트/툴팁. 현재 아이콘은 Art/Sprites/UI에 있습니다.
- 화물: TransportItemSO 이름·아이콘·색·무게·보상. CargoToolkitScreen.Minimum Selected Slots는 최소 표시 칸 수입니다. 빈 칸/적재 칸은 같은 크기이며, 적재 칸을 누르면 수량 조절/비우기 상세 창을 엽니다.
- 함대 카드: Shared/ShipCard.uxml. 아군/적군 영역은 동일 Flex로 50:50입니다. 전체 편성 해제는 호위선 전 슬롯을 비우며 메인 함선은 고정입니다.
- 모집/합성: 각 ToolkitScreen의 공개 연출 시간·크기. 게임 비용/소모 규칙은 기존 Manager에서 조절합니다.

## 애니메이션과 시간

함대·적재는 열기 전 시간 배율을 보관하고 닫을 때 복원합니다. UI 반복 입력·획득 로그·모집/합성 결과·정산은 unscaled 시간을 사용합니다. InGameFeedbackToolkit의 정산 카운트/페이드/진입 크기와 스테이지 팝업/전환 시간을 Inspector에서 바꿉니다.

전환 페이드 완료 이벤트는 다음 해역 진입과 연결됩니다. 기존 ScreenFadePanelControler를 함께 활성화하면 중복 진행될 수 있습니다. 기존 비활성 화면과 Setup 도구를 재활성화하기 전에 현행 문서의 연결을 확인합니다.

## 한글과 화면 비율

Toolkit은 Shared/Settings/HarborTextSettings.asset → HarborKorean.asset을 사용합니다. USS의 -unity-font-definition도 같은 TextCore 폰트를 참조합니다. 새 글자가 네모이면 글리프·Dynamic/Fallback·콘솔 경고를 확인합니다.

기준은 1080×1920 너비 스케일입니다. 기준 외 비율, Safe Area, 실기기 터치는 별도 확인이 필요합니다. 자동 테스트는 이번 이관에서 추가/실행하지 않았습니다.
