# 함대 편성·모집·합성

## 상태 소유자

PlayerFleetManager가 카탈로그, 보유 수량, 호위선 8칸 편성을 관리합니다. UI는 이 상태를 읽고 배치/합성 요청을 보냅니다. StageSpawnManager는 PlayerFleetLoadout을 실행용으로 복제하고 실제 프리팹 편성을 동기화합니다.

## 초기 함대 설정

1. 씬의 PlayerFleetManager를 선택합니다.
2. Catalog에 EscortShipCatalog를 연결합니다.
3. Initial Owned Escorts에 Ship Data와 Amount를 입력합니다.
4. Initial Formation 8칸에 시작 함대를 넣습니다. 같은 함선을 두 칸에 배치하려면 해당 종류를 최소 2척 보유해야 합니다.
5. StageSpawnManager의 Player Fleet Manager/Player Fleet Loadout/호위 스폰 8칸을 확인합니다.

PlayerFleetLoadout의 본선 설정과 PlayerFleetManager의 초기 편성은 역할이 다릅니다. 보유형 함대를 쓰는 씬에서는 Loadout의 호위 프리팹 배열만 바꾸고 결과가 고정될 것으로 가정하지 마세요. Manager가 런타임 Loadout에 현재 편성을 반영합니다.

## 편성 사용법

함대 화면에서 함선 카드를 선택하고 편성 슬롯을 선택합니다. 빈 칸 배치, 기존 칸 교체/제거 흐름은 PlayerFleetPanelController가 처리하고 Manager가 보유 수를 검사합니다. 편성은 05번의 3열×3행 격자에서 본함 중앙 후열을 제외한 8칸을 따릅니다.

편성 변경 → Manager 상태 변경 → 런타임 Loadout 버전 증가 → 다음 전투 준비 시 변경 감지 → 기존 함대 회수/새 편성 생성 순입니다. 전투 현장의 Clone을 직접 다른 프리팹으로 바꾸는 방식은 사용하지 않습니다.

## 모집 설정

EscortGachaManager의 Currency Manager, Player Fleet Manager, Gacha Table을 연결합니다. Currency Type과 Summon Cost를 조절하면 모집 비용이 바뀝니다. 카드 화면의 Multi Count는 여러 번 모집하는 UI 수량입니다.

테이블의 Weight는 양의 정수이며 `해당 Weight / 전체 합`이 확률입니다. 카탈로그에만 등록한 함선은 자동으로 모집 테이블에 들어가지 않습니다. 반대로 모집 테이블의 보상도 실제 카탈로그에서 지급 가능한 함선인지 확인해야 합니다.

TrySummon은 설정·보상·재화를 검사하고 차감 후 지급합니다. 지급 실패 때는 환불하는 경로가 있습니다. 여러 번 모집의 실제 획득 수는 재화와 지급 성공 여부에 따라 달라질 수 있으므로 결과 화면을 확인하세요.

## 합성 규칙 세 가지

| 경로 | 재료 선택 방식 |
|---|---|
| 현재 합성 화면 | 같은 등급의 미편성 3척을 사용자가 직접 선택 |
| 기존 TryMerge API | 선택 종류 우선, 부족분은 카탈로그 순서의 같은 등급 |
| MergeAllUnequipped | 미편성 함선을 낮은 등급부터 일괄 처리 |

합성 결과는 **다음 등급의 카탈로그 첫 항목**입니다. 편성 중인 복사본은 재료로 소비하지 않습니다. Legendary는 더 합성하지 않습니다. 다음 등급 데이터가 없으면 재료를 먼저 잃는 방식으로 처리하지 않습니다.

## 수동 합성 사용

1. 함대 화면에서 함선 합성을 엽니다.
2. 같은 등급의 미편성 재료를 3칸에 선택합니다. 같은 종류도 여유 수량만큼 여러 번 선택할 수 있습니다.
3. 상위 등급 미리보기와 선택 수를 확인합니다.
4. 합성 버튼을 누릅니다. 재료 칸을 누르면 선택 해제할 수 있습니다.
5. 보유 수량에서 3척이 줄고 결과 1척이 늘었는지 확인합니다.

일괄 합성 버튼을 사용하는 경우 이번 처리에서 얻은 상위 등급도 다시 재료가 될 수 있습니다. 예를 들어 Common 9척 → Uncommon 3척 → Rare 1척으로 이어질 수 있습니다. 사용자가 명시적으로 실행하는 버튼 동작이며, 모든 보유함을 편성 여부와 무관하게 소비하는 기능은 아닙니다.

## 화면과 시간 정지

FleetScreenPause는 이전 Time.timeScale을 보관하고 함대 화면에서 전투를 멈춥니다. 합성 화면만 닫으면 함대 화면의 정지가 유지됩니다. 함대 화면을 닫으면 이전 속도로 복원합니다. PanelFadeIn은 unscaled 시간으로 재생하므로 전투 정지 중에도 화면이 나타납니다.

## 문제 확인

- 편성 불가: 보유 수량에서 편성 중 수량을 빼고 여유 복사본 확인.
- 합성 결과 예상과 다름: 카탈로그의 다음 등급 첫 항목 확인.
- 카드 아이콘 없음: EscortShipData.Icon 확인.
- 설정 변경 후 테스트가 반복됨: 실행 중 상태와 영구 저장을 혼동하지 않았는지 확인.
