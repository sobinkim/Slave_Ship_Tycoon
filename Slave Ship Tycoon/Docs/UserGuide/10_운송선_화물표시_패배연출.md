# 운송선·화물 표시·패배 연출

현재 운송 본선은 `Assets/SB/Prefabs/PlayerShips/TransportMainShip.prefab`입니다. 공격하는 호위함과 역할이 다르며 공격 컴포넌트/TargetSelector가 없습니다. MainShipDestruction이 일반 피해를 0으로 처리하고, 호위함 전멸 뒤 최후 일제사격으로 패배를 연출합니다.

## 연결 구조

```text
TestPlayerFleetLoadout.Main Ship Prefab → TransportMainShip
StageSpawnManager.Cargo Manager → 씬 CargoManager
생성 시 MainShip.Cargo Visualizer에 CargoManager 전달
MainShip.Destruction → 프리팹 MainShipDestruction
MainShipDefeatDirector → 전멸 확인·적 일제사격·패배 타이밍
```

본선의 EntityHealth와 ShipStatCompo는 기존 지휘·업그레이드 연결을 위해 남아 있습니다. 일반 체력 소모로 죽는 함선으로 바꾸고 싶으면 무적 처리와 패배 Director 흐름까지 함께 설계해야 합니다.

## 궤짝 표시 수

금화 화물과 함선 재료 화물의 **실제 Amount 합계**만큼 궤짝을 표시합니다. 표시 개수와 적재 무게는 다릅니다. 적재 가능 여부는 CargoManager와 BaseWeight가 결정합니다. 같은 궤짝 그림을 쓰며 표시 개수 상한으로 게임 화물을 제한하지 않습니다.

Column Base Points 배열 순서대로 열을 채운 뒤 다음 단으로 쌓습니다. 5열이라면 15개는 3단, 16개는 4단 첫 궤짝입니다. 숨긴 궤짝은 이후 적재에 재사용합니다.

## 갑판과 궤짝 커스텀

1. Prefab Mode에서 Visual/CargoDeck의 Column_01~05를 찾습니다.
2. 열의 Local Position을 조절해 갑판 시작점을 맞춥니다.
3. 열 추가/삭제 시 ShipCargoVisualizer의 Column Base Points도 직접 수정합니다. 이름만 Column_06으로 만들면 자동 연결되지 않습니다.
4. Stack Local Offset으로 단 사이 간격을 조절합니다.
5. `Assets/SB/Prefabs/Cargo/TransportCargoCrate.prefab`의 Scale로 개별 궤짝 크기를 조절합니다.
6. Crate Sorting Order와 앞 난간 SpriteMask의 범위를 확인합니다.
7. 적재·하역·혼합 적재·판매 후 수량을 확인합니다.

| ShipCargoVisualizer 값 | 의미 |
|---|---|
| Crate Prefab | 표시 궤짝 SpriteRenderer |
| Drop Seconds/Drop Local Height | 낙하 시간·높이 |
| Drop Progress Curve | 낙하 진행 곡선 |
| Load Stagger Seconds | 여러 개 증가할 때 시작 간격 |
| Settle Seconds | 착지 눌림 시간 |
| Landing Scale Multiplier | 착지 순간 가로/세로 비율 |

Visual 확대는 갑판 위치와 함께 확대됩니다. 체력바·물살 등은 실제 계층을 보고 별도로 맞추세요. 적재 용량은 궤짝 Scale이 아니라 강화/CargoManager 설정으로 조절합니다.

## 현재 패배 순서

1. MainShipDefeatDirector가 살아 있는 호위함이 없고 살아 있는 적이 있는지 확인합니다.
2. 적의 일반 공격을 중단하고 기존 비행탄을 취소합니다.
3. Preparation Seconds만큼 기다립니다.
4. 생존 적마다 한 발을 같은 프레임에 발사합니다.
5. 최후 탄은 Guaranteed 명중, 피해 0, 동일 비행 시간으로 처리합니다.
6. 모든 탄의 해결 콜백이 도착하면 본선 표시를 숨기고 On Defeat Presentation을 실행합니다.
7. Defeat Hold Seconds만큼 장면을 유지한 뒤 기존 사망/패배 이벤트로 연결합니다.

현재 최종 구성은 폭발 파티클을 제거한 상태입니다. 과거 TransportMainShip 작업 기록의 폭발 검증은 이전 단계 기록입니다. 약한 화면 흔들림은 On Defeat Presentation에 연결된 PlayDefeatShake에서 조절합니다.

## Inspector 설정

MainShipDefeatDirector의 Salvo Projectile Prefab, Salvo Muzzle Effect Prefab, Preparation Seconds, Salvo Flight Seconds, Salvo Arc Height, Projectile Life Margin Seconds, Enemy Attack State Name, Defeat Hold Seconds를 확인합니다. 새 적은 ArcProjectileAttackCompo와 실제 Fire Point가 필요합니다.

MainShipDestruction의 Owner/Presentation Roots에는 본선과 **숨길 시각 오브젝트**를 연결합니다. 관리 컴포넌트가 있는 본선 루트 전체를 무심코 숨김 목록에 넣지 마세요. Hit Feedback과 On Defeat Presentation도 확인합니다. 운송선 ShipHullFeedback의 Show Health Bar는 꺼 두는 구성이 현재 의도입니다.

## 확인 방법

호위함이 있는 전투 → 호위함 전멸 → 모든 적 동시 발사 → 전탄 명중 뒤 표시 숨김 → 대기 후 패배를 봅니다. 처음부터 호위함 0척인 경우도 확인합니다. 일제사격 중 전투 초기화/종료 시 이전 콜백이 새 출항의 본선을 죽이지 않는지도 확인해야 합니다.
