# 철갑 방어함 사용과 커스텀

## 주요 파일

- 프리팹: `Assets/SB/Prefabs/PlayerShips/IroncladDefender.prefab`
- 함선 데이터: `Assets/SB/Data/PlayerFleet/EscortShips/Escort_IroncladDefender.asset`
- 공유 보호 효과: `Assets/SB/Data/FleetEffects/ImmediateRearProtection.asset`
- 애니메이션: `Assets/SB/Animations/Ships/IroncladDefender`
- 선체 재질: `Assets/SB/Art/Materials/Ships/IroncladHull.mat`
- 작업 기록: `QA/IroncladDefender.md`, `QA/IroncladCombatAnimation.md`, `QA/FleetShieldEffects.md`

## 사용하는 위치

아군 편성의 오른쪽 전열(열 1)에 넣고 같은 행 왼쪽 뒤 칸(열 0)에 지킬 함선을 넣습니다. 바로 뒤 칸이 비면 다른 행이나 먼 슬롯을 보호하지 않습니다. Tanker 역할만으로 보호가 붙지 않고 Provider/효과 연결이 실제 기능을 제공합니다.

## 새 방어함 양산

1. IroncladDefender 프리팹과 EscortShipData를 복제합니다.
2. 새 이름·고유 Stable Id·아이콘·등급을 설정합니다.
3. 새 그림으로 Visual과 모든 상태의 Sprite 키를 교체합니다.
4. 체력·공격력·공속·공격 간격을 조절합니다.
5. Provider의 Owner/Source Receiver/Effects, Receiver의 Presentations를 확인합니다.
6. 보호율을 이 함선만 다르게 하려면 ImmediateRearProtection을 복제해 연결합니다.
7. 카탈로그/모집/초기 보유량 등록 후 전열과 후열 배치를 비교합니다.

## 포구와 침몰

ShootPos/Fire Point는 탄 위치, Visual/MuzzleVfx는 화염·연기 위치입니다. 둘은 별도 Transform일 수 있으므로 총구를 옮길 때 함께 맞춥니다. MuzzleFlash/MuzzleSmoke의 크기는 자식 Scale에서, 표시 시간은 Attack 클립의 Renderer Enabled 트랙에서 조절합니다.

IroncladHull의 Waterline은 수면 기준, Sink Distance는 침몰 거리입니다. Dead 클립의 Sink Progress가 0→1로 변화하며 선체가 수면 아래로 가려집니다. Idle/Move/Attack에서 진행도를 복원하는 트랙도 확인합니다.

## 방패와 체력바

ShieldAnchor의 위치·각도·크기를 외형에 맞추고 ShipShieldVisual의 제공자/수신자 색을 조절합니다. 체력바는 WorldUI/HullCondition에서 별도로 맞춥니다. 효과 아이콘은 보호를 받는 쪽에 표시되는 것이므로 공급자의 파란 방패와 동일 조건으로 나오지 않습니다.

## 확인할 상황

전열 공급, 후열 배치, 빈 뒤 칸, 다른 행, 방어함 사망, 전투 종료, 다음 출항을 봅니다. 보호받는 함선의 직접 타겟 제한과 피해 감소를 둘 다 확인하세요. 자세한 보호 연결은 [09번](09_보호효과와_방패_아이콘.md)을 사용합니다.
