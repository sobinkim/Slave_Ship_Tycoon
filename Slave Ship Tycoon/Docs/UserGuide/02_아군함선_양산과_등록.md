# 아군 함선 양산과 등록

새 호위함 한 종류를 추가하려면 **전투 프리팹, 함선 데이터, 카탈로그 등록**이 필요합니다. 모집으로 얻도록 하려면 가챠 테이블에도 등록합니다. 프리팹만 복제하면 모집 목록에 자동으로 추가되지 않습니다.

## 어떤 프리팹을 복제할까요?

| 원하는 기능 | 출발 프리팹 |
|---|---|
| 일반 포탄 공격 | `Assets/SB/Prefabs/PlayerShips/Test/TestEscort_A.prefab` 등 |
| 후열 보호 제공 | `Assets/SB/Prefabs/PlayerShips/IroncladDefender.prefab` |
| 보호받는 후열을 직접 공격 | `Assets/SB/Prefabs/PlayerShips/HarpoonRaider.prefab` |
| 전열 고체력 우선 말뚝 공격 | `Assets/SB/Prefabs/PlayerShips/CrusherShip.prefab` |
| 본선 교체 | TransportMainShip. 호위함 제작과 분리해서 10번 문서를 사용 |

새 종류가 원본과 독립적으로 바뀌어야 하면 일반 복제를 사용합니다. 원본 개선을 계속 상속받아야 하면 Prefab Variant를 고려하세요. Variant의 공유 설정과 Overrides를 이해한 상태에서 선택합니다.

## 1. 프리팹 제작

1. 재생을 종료합니다. Project 창에서 기준 프리팹을 선택해 Duplicate하고 새 이름을 지정합니다.
2. 새 프리팹을 더블클릭합니다. 루트 Ship의 Ship Type이 EscortShip인지 확인합니다.
3. Entity Name과 Ship Role을 설정합니다. Role은 타겟 분류이며, Tanker를 선택하는 것만으로 보호 기능이 생기지 않습니다.
4. Visual의 SpriteRenderer 그림을 변경합니다. Animator 클립에도 원본 Sprite가 들어 있으면 재생 시 원래 그림으로 돌아가므로 클립까지 확인합니다.
5. 새 함선 전용 움직임이면 Animator Controller와 필요한 클립도 복제하여 연결합니다. 공유 클립을 수정하면 원본 함선에도 영향을 줍니다.
6. ShipStatCompo의 Stat Container/Stat Overrides에서 체력·공격력·공격속도를 조절합니다. 공용 StatSO 참조는 유지하고 개별 기본값을 바꾸는 것이 일반적입니다.
7. 공격 컴포넌트의 Attack Cooldown, Projectile Prefab, Fire Points, Flight Data를 설정합니다.
8. TargetSelector의 Target Rules와 Selection Mode를 설정합니다.
9. 발사점·피격점·물 착탄점, 체력바·물살·방패 위치를 새 외형에 맞춥니다.
10. Owner, Health, Hull, Receiver 등 참조가 복제한 프리팹 내부를 가리키는지 확인하고 저장합니다.

Entity는 자식 컴포넌트를 초기화합니다. 이름이 `AboutBattle`인지보다 올바른 컴포넌트와 참조가 있는지가 중요합니다. 기존 계층 이름은 팀이 찾기 쉽게 유지하세요.

## 2. 함선 데이터 만들기

Project 창에서 `Create > SB > Fleet > Escort Ship Data`를 사용하거나 기존 EscortShipData를 복제합니다. 추천 위치는 `Assets/SB/Data/PlayerFleet/EscortShips`입니다.

| 필드 | 입력 방법 |
|---|---|
| Stable Id | 종류마다 유일한 ID. 예: `escort_new_cannon` |
| Display Name | 카드에 보여줄 한국어 이름 |
| Icon | 카드용 Sprite |
| Grade | Common/Uncommon/Rare/Epic/Legendary |
| Ship Prefab | 방금 만든 프리팹의 Ship |

복제 후 Stable Id를 반드시 바꾸세요. 중복 ID는 카탈로그 검증에서 실패합니다. 같은 그림을 쓰더라도 데이터 종류가 다르면 ID를 구분합니다.

## 3. 카탈로그와 모집에 등록

1. `Assets/SB/Data/PlayerFleet/EscortShipCatalog.asset`의 Ships에 새 데이터를 추가합니다.
2. 기존 순서를 임의로 정렬하지 마세요. 합성 결과는 **카탈로그에서 처음 발견한 다음 등급**입니다.
3. 모집에 넣으려면 `EscortGachaTable.asset`의 Entries에 새 데이터와 양의 Weight를 추가합니다.
4. 동일 데이터를 가챠 테이블에 두 번 넣지 않습니다. 확률은 `Weight / 전체 Weight 합`입니다.
5. 무료 테스트 지급은 씬 PlayerFleetManager의 Initial Owned Escorts에 추가합니다.
6. 처음부터 편성하려면 Initial Formation에도 넣고 그만큼 보유 수량을 제공합니다.

예: 기존 가중치 합이 100일 때 25를 추가하면 새 함선 확률은 25%가 아니라 25/125=20%입니다. 이것은 계산 예시이며 현재 테이블 값은 직접 확인하세요.

## 양산 예시: 같은 함종으로 세 등급 만들기

기본 프리팹을 복제해 Common/Uncommon/Rare 버전을 만듭니다. 각 프리팹의 Stat Overrides와 외형을 바꾸고, 데이터 3개에 고유 ID와 등급을 넣습니다. 모두 카탈로그에 등록하되 다음 등급 첫 항목이 합성 결과라는 점을 확인합니다. 현재 구조에는 “같은 함종의 상위 등급으로 자동 진화” 규칙이 없으므로 이름만 맞춰서는 계통 합성이 되지 않습니다.

## 확인 순서

- Prefab Mode와 실제 Idle/Move/Attack/Dead에서 같은 외형인지 봅니다.
- 새 함선 1척만 편성해 공격, 피격, 사망을 봅니다.
- 다음 출항에서 원래 외형·체력·장전 상태가 복원되는지 확인합니다.
- 카드 아이콘, 모집 획득, 편성 교체를 확인합니다.
- 효과 제공 함선을 복제했다면 의도하지 않은 Provider가 남아 있지 않은지 확인합니다.

카드만 나오고 함선이 안 뜨면 Ship Prefab과 실제 런타임 편성/스폰 지점을 확인하세요. 그림이 되돌아오면 Animator의 Sprite 키를 확인하세요.
