# 적 함선 양산과 보스 설정

적은 아군 카탈로그를 통해 생성하지 않습니다. **Enemy 프리팹을 웨이브의 Enemy Slots에 연결**하면 해당 웨이브에서 나옵니다.

## 일반 적 제작

1. `Assets/SB/Prefabs/EnemyShips/Test/TestEnemy_A.prefab` 또는 B/C 중 가장 비슷한 동작을 복제합니다.
2. 새 이름으로 저장하고 Prefab Mode를 엽니다.
3. 루트에 Enemy 컴포넌트가 있고 Ship Type이 Enemy인지 확인합니다. 단순 Ship 프리팹은 Enemy Slots의 Enemy 참조를 대체할 수 없습니다.
4. Entity Name, Role, 체력·공격력·공격속도 기본값을 정합니다.
5. Visual 그림과 Animator 클립의 Sprite 키를 함께 교체합니다.
6. TargetSelector의 공격 대상 규칙을 설정합니다. 아군과 적은 전열의 방향이 다르므로 05/07번을 함께 읽습니다.
7. 공격 컴포넌트의 Projectile Prefab/Fire Points/Flight Data를 확인합니다. 계층 이름이 ArcProjectileAttackCompo여도 실제 컴포넌트가 Test_ShipAttackCompo일 수 있으므로 Inspector의 스크립트 제목을 확인하세요.
8. ShipProjectileAnchorCompo의 Hit Point, Water Impact Point를 새 선체에 맞춥니다.
9. WorldUI/HullCondition, 물살, 위험 표시, 회피·피격 효과 위치와 참조를 점검합니다.
10. EnemyRewardDropCompo의 Reward Type을 정하고 저장합니다.

새 적마다 능력치를 다르게 만들고 싶으면 적 프리팹을 각각 복제해 Stat Overrides를 바꿉니다. 현재 StageEnemyLayout은 Enemy 프리팹만 저장하므로 “이 웨이브에서만 체력 2배” 같은 슬롯별 배율 필드는 없습니다. 그런 기능은 추가 구현이 필요합니다.

## 보스 제작

`Assets/SB/Prefabs/EnemyShips/Test/TestBoss.prefab`을 복제하면 기존 보스 구성을 출발점으로 삼을 수 있습니다. 별도 보스 레이아웃을 만들어 보스와 호위 적을 배치하고, 해당 ChapterContainer의 **Boss Layout**에 연결합니다.

보스 프리팹 이름이 Boss라고 해서 자동으로 보스전으로 분류되지 않습니다. Boss Layout과 GameFlowManager.StartBossBattle의 경로가 보스전을 결정합니다. Obtain 챕터의 Stages에 보스 레이아웃을 넣으면 일반 랜덤 웨이브에 등장할 수 있으니 Boss Layout과 구분해서 등록하세요.

보스 외형 확대는 루트 전체보다 Visual을 먼저 조절합니다. 크게 만든 뒤 발사점·피격점·체력바·방패를 별도로 맞춥니다. 스폰 간격도 늘려야 하는지 05번에서 확인하세요.

## 아군 디자인을 적으로 사용하고 싶다면

아군 그림·재질·애니메이션을 재사용할 수는 있습니다. 다만 아군 프리팹의 Ship Type만 Enemy로 바꾸면 루트 타입은 여전히 Ship이며 Enemy 슬롯에 연결되지 않을 수 있습니다. 기존 **Enemy 프리팹을 기반으로 시각 에셋을 가져오는 방식**이 제작자가 확인하기 쉽습니다. 방어 능력이 필요하면 FleetEffectProvider를 명시적으로 구성합니다.

## 최후 일제사격 대응

새 적은 일반 전투뿐 아니라 본선 패배 연출도 확인해야 합니다. MainShipDefeatDirector가 새 적의 `ArcProjectileAttackCompo`와 명시적 Fire Point를 필요로 하므로 해당 타입을 상속하지 않는 공격 방식은 자동 대응된다고 가정하지 마세요. Enemy Attack State Name과 Animator의 상태도 확인합니다.

## 웨이브에 넣고 확인하기

1. 04번 안내대로 기존 웨이브를 복제하거나 Layout Editor에서 새 웨이브를 만듭니다.
2. 빈 칸에 새 Enemy 프리팹을 넣습니다.
3. ChapterContainer의 Stages 또는 Boss Layout에 연결합니다.
4. 한 전투에서 공격, 피해, 처치 보상, 사망 연출을 확인합니다.
5. 동일 웨이브를 다시 실행하여 체력·스프라이트·타겟·효과가 정상 초기화되는지 확인합니다.
6. 호위함이 전멸했을 때 새 적이 최후 일제사격에 참여하는지 확인합니다.

| 증상 | 먼저 확인할 곳 |
|---|---|
| 슬롯에 프리팹을 넣을 수 없음 | Enemy 컴포넌트가 있는 프리팹인지 |
| 다른 적까지 수치가 바뀜 | 공유 StatSO 또는 원본 프리팹을 수정했는지 |
| 새 적이 안 나옴 | 웨이브가 실제 ChapterDatabase에 등록되어 있는지 |
| 총구가 반대 방향/몸 밖에서 발사 | Visual 방향, Fire Points, 애니메이션 위치 |
| 처치 후 보상이 없음 | EnemyRewardDropCompo와 해당 챕터 Reward Table |
