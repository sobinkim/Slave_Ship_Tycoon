# 프로젝트 사용설명서

이 설명서는 AI 작업 기록, 현재 C# 코드, 프리팹·데이터 파일, Unity에서 확인한 연결을 바탕으로 작성했습니다. 기준일은 **2026-10-02**입니다. 작업 기록만으로 모든 코드의 작성자를 확정할 수는 없어, AI 작업과 연결된 현재 게임 시스템 전체를 안내합니다.

처음에는 전체 구조를 읽고, 실제로 바꾸고 싶은 기능의 문서로 이동하면 됩니다. 각 문서는 설정 위치, 사용 순서, 콘텐츠 추가 방법, 문제 해결을 함께 설명합니다. `Assets/SB/Docs`와 `QA`의 기존 문서는 작업 당시 기록이며, 이 폴더는 현재 구조를 사용하는 사람을 위한 안내입니다.

## 먼저 알아두기

- **프리팹**: 함선·탄·UI의 설계도입니다. Project 창에서 더블클릭해 Prefab Mode로 편집합니다.
- **데이터 에셋(ScriptableObject)**: 함선 목록, 웨이브, 스킬 등 설정을 담은 파일입니다. Project 창에서 선택하고 Inspector를 편집합니다.
- **씬**: 실제 게임 화면과 관리자들의 연결입니다. 기본 씬은 `Assets/SB/Animations/Scenes/SampleScene.unity`입니다.
- **참조 연결**: Inspector의 오브젝트 칸에 해당 오브젝트나 에셋을 드래그하는 작업입니다.
- **런타임**: Play를 누른 뒤의 실행 상태입니다. 재생 중 변경한 씬 상태는 종료하면 돌아갈 수 있고, 데이터 에셋 변경은 저장될 수 있습니다. 콘텐츠 설정은 재생을 종료한 뒤 하세요.
- 문서의 코드 필드명은 검색용입니다. Inspector에서는 공백이 추가된 이름으로 보일 수 있습니다. 예: `spawnPoints` → Spawn Points.
