# 지휘 스킬과 게이지

## 데이터와 실행 상태

CommanderSkillData는 이름·아이콘·비용·쿨다운·지속시간을, CommanderSkillDatabase는 사용 가능한 스킬 목록을, CommanderSkillLoadout은 장착 슬롯을 정의합니다. CommanderSkillManager는 실행 중 게이지·쿨다운·활성 효과·AUTO를 관리합니다.

데이터 위치는 `Assets/SB/Data/Commander`입니다. 기존 TotalOffensive/FocusFire와 Database/Loadout을 확인하세요. Manager의 Skill Database/Skill Loadout을 명시적으로 연결합니다.

## 기본 스킬 설정

| 공통 필드 | 의미 |
|---|---|
| Skill Id | 스킬 식별자 |
| Display Name/Description/Icon | 화면 표시 |
| Gauge Cost | 사용 시 게이지 소비 |
| Cooldown | 재사용 대기 시간 |
| Duration | 효과 지속시간 |

TotalOffensiveSkillData에는 Attack Speed Increase Percent가 추가됩니다. 전체 공격의 속도를 증가시키는 Support 스킬입니다. FocusFire는 Attack 카테고리로 적의 목표 열을 지정하는 효과를 사용합니다. 게이지와 최대치·회복량은 본선 지휘 스탯 및 강화와 연결됩니다.

## 장착·사용

1. CommanderSkillDatabase의 Skills에 사용할 에셋을 넣습니다.
2. CommanderSkillLoadout의 Equipped Skills에 장착 순서대로 연결합니다. 같은 SkillType을 중복 장착하지 않습니다.
3. CommanderSkillBarController/슬롯 View의 Manager·텍스트·아이콘·쿨다운 Fill을 확인합니다.
4. 전투에서 게이지가 충분하고 스킬이 준비되면 버튼으로 사용합니다.
5. 지속시간/쿨다운 표시와 실제 공격 변화를 확인합니다.

UI는 잠금·준비·활성·쿨다운을 표시하는 역할입니다. 버튼 텍스트만 바꿔도 스킬 효과가 변하지 않습니다.

## AUTO

Manager의 Is Auto Use Enabled와 Auto Use Check Interval을 조절합니다. AUTO는 사용 가능한 Support 스킬을 우선 보고, 없으면 Attack을 시도하는 흐름입니다. 한 번의 검사마다 보유 스킬을 무조건 모두 발동하는 기능은 아닙니다.

게이지 부족, 쿨다운, 비활성 전투, 효과 대상 없음 등의 조건은 CanUseSkill/TryUseSkill과 효과 CanActivate에서 검사합니다.

## 같은 스킬의 다른 수치 만들기

기존 에셋 복제 → 비용/지속/쿨다운/공속 변경 → Database와 Loadout에서 원하는 버전으로 교체합니다. 현재 Database는 SkillType으로도 조회하므로 같은 타입 두 버전을 동시에 등록하면 중복 경고와 첫 항목 조회 문제가 생길 수 있습니다. 수치 변형은 활성 목록에서 하나를 선택하는 방식으로 쓰세요.

## 완전히 새로운 효과 추가

새 이미지와 에셋만 추가해서는 새 기능이 동작하지 않습니다. CommanderSkillType enum, CommanderSkillData 파생 타입, CommanderSkillEffects의 효과 구현, Manager의 효과 생성 분기, Database/Loadout/UI를 함께 연결해야 합니다.

지속 버프는 Activate와 Deactivate를 짝으로 구현하고 사망·전투 종료·풀 반환 때 남지 않도록 해야 합니다. TotalOffensive는 공급 키별 공속 보정을 추가/제거하며, FocusFire는 명령 대상 열을 정리합니다.

## 확인 방법

수동 사용 시 게이지 차감/지속 종료/쿨다운 완료를 보고 AUTO 켜기·끄기도 확인합니다. 전투 종료나 편성 변경 뒤 새 전투에 이전 공속 버프·지휘 타겟이 남는지 점검합니다. 게이지가 회복되지 않으면 본선 ShipStatCompo의 지휘 StatSO와 MainShipUpgradeData의 관련 값을 확인하세요.
