# 피격·회피·위험 표시

전투 판정과 표시를 구분해서 조절하세요. 물 위의 빨간 경고는 들어오는 탄을 보여주고, MISS는 회피 결과를 보여줍니다. 표시 색이나 크기를 바꿔도 공격 피해·회피 확률은 바뀌지 않습니다.

## 구성별 역할

| 구성 | 역할 |
|---|---|
| ShipHullFeedback | 체력바·선체 피격 피드백 |
| ShipIncomingFireDisplay | 표적을 향해 비행하는 탄의 수·위험도 |
| ShipProjectileEvasion | 함선 운과 설정 에셋으로 회피 판정 |
| ShipMissFeedback | MISS 문구 |
| ShipWoodImpactFeedback/WoodImpactEffect | 나무 파편 |
| NormalProjectile | 명중/물 착탄 효과 연결 |
| DamageFloatingTextPresenter/FloatingTextManager | 피해 숫자 표시 |
| CameraImpactShake | 요청된 카메라 흔들림 |

## 체력바 조절

프리팹 `WorldUI/HullCondition`의 Local Position으로 위치를 맞춥니다. ShipHullFeedback의 Health/Hull/Health Fill/Health Bar 참조를 확인합니다. Bar Width/Bar Height는 길이·두께, Health Drain Seconds는 감소 표시 시간, Danger Threshold/Healthy Color/Danger Color는 체력 색 기준입니다. Always Show Health는 상시 표시, Show Health Bar는 표시 자체를 선택합니다. 운송 본선은 후자를 끈 구성이 현재 의도입니다.

체력바가 다른 함선과 겹치면 05번의 행 간격과 함께 조절하세요. Visual 크기와 체력바 크기가 독립적일 수 있으므로 루트 전체 확대부터 적용하지 마세요.

## 위험 탄 수

ShipIncomingFireDisplay의 Ship/Health/Hull/Water Decal/Count Label을 명시적으로 연결합니다. 숫자는 현재 등록된 모든 비행 중 탄을 세고, 위험도는 **Danger Window Seconds 이내에 도착할 탄의 예상 피해 / 현재 HP**를 사용합니다. 두 표시가 서로 다른 범위를 사용합니다.

Warning Color, Idle Alpha, Danger Alpha, Fade Seconds, Danger Health Ratio, Decal Sorting Offset을 조절합니다. Danger Health Ratio가 낮으면 상대적으로 적은 예상 피해에서도 강하게 강조됩니다. 데칼의 위치·가로세로 비율은 연결된 Transform, 링 굵기는 재질에서 맞춥니다.

탄의 회피·명중·취소·전투 종료가 표시 해제와 연결되어야 합니다. 숫자를 직접 수정해 실제 등록 상태를 바꾸지 마세요.

## 회피 확률

ShipProjectileEvasion의 Combat Stats, Settings, Left Water Point, Right Water Point를 확인합니다. 설정 에셋은 `Assets/SB/Art/Effects/CannonWaterSplashPreview/ProjectileEvasionSettings.asset`을 참고할 수 있습니다.

확률은 `MaximumMissChance × Luck / (Luck + LuckForHalfMaximum)`입니다. 운 0이면 0, LuckForHalfMaximum과 같은 운이면 상한의 절반이며 높은 운에서도 상한에 가까워집니다.

예: 상한 0.15, 반상한 운 50이면 운 50의 회피율은 7.5%입니다. 운 100이 회피율 100%라는 의미는 아닙니다. 아군의 최종 운은 고유 Base Luck과 함대 강화 운을 합치고, 적은 고유 운을 사용합니다.

회피 때 들어오는 방향에 맞는 물 착탄점과 물기둥 표시를 사용합니다. Guaranteed 모드의 최후 일제사격은 일반 회피를 적용하지 않습니다.

## MISS·파편·물기둥

ShipMissFeedback의 Label/Visible Seconds/Minimum Interval Seconds/Rise Local Units로 문구를 조절합니다. 최소 간격은 문구 반복 제한이며 실제 회피 횟수를 제한하지 않습니다.

ShipWoodImpactFeedback의 Effect Prefab/Minimum Interval Seconds로 파편 생성을 조절합니다. NormalProjectile의 Water Splash Effect Prefab과 Sorting 설정을 확인합니다. 물기둥 프리팹의 ParticleSystem/Renderer가 실제 효과를 만듭니다. 과거 제거한 ImpactBurst를 현재 필수 구성으로 다시 붙이지 않습니다.

## 흔들림·피해 숫자

CrusherStakeImpactShake는 말뚝 명중의 Shake Distance Units/Duration Seconds를 요청합니다. CameraImpactShake의 Cooldown Seconds는 반복 명중 흔들림 간격입니다. 본선 패배 흔들림은 MainShipDestruction의 이벤트와 별도로 조절합니다.

FloatingTextManager에는 Target Canvas/Text Root/World Camera와 타입별 View Datas를 연결합니다. 화면 좌표 변환이 어긋나면 카메라와 Canvas 설정부터 봅니다.

## 확인 방법

한 척에 여러 탄 집중 → 카운트 변화 → 명중/회피 후 감소 → 표적 사망 → 전투 종료 → 풀 재사용을 확인합니다. 확률은 짧은 플레이 한 번으로 결론내리지 말고 충분한 표본이나 ProjectileEvasionTests를 사용하세요.
