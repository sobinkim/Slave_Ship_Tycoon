# 공격·발사체·애니메이션 설정

## 공격이 실행되는 구조

Ship이 Attack 상태에 들어가면 Animator가 공격 동작을 재생합니다. 실제 발사는 클립의 **AttackStart 이벤트**가 EntityAnimatorTrigger에 전달된 뒤 공격 컴포넌트에서 실행됩니다. AttackEnd 이벤트는 공격 종료 처리에 사용됩니다. 따라서 그림이 움직이는 것만으로 탄이 발사되지는 않습니다.

```text
타겟 확보 → 공격 상태/애니메이션
 → AttackStart → 발사점에서 탄 생성 → 비행 → 명중/회피
 → AttackEnd → 다음 공격 준비
```

## Inspector 조절

| 위치 | 필드 | 의미 |
|---|---|---|
| Base_ShipAttackCompo 계열 | Attack Cooldown | 기본 공격 간격(초) |
| ArcProjectileAttackCompo 계열 | Projectile Prefab | 실제 날아갈 탄 |
| 동일 컴포넌트 | Fire Points | 순서대로 번갈아 사용할 총구 Transform |
| Flight Data | Flight Speed | 탄 이동 속도 |
| Flight Data | Arc Height | 포물선 높이 |
| Flight Data | Minimum Flight Duration | 가까운 표적에도 적용할 최소 비행 시간 |
| Flight Data | Life Time | 탄의 최대 수명 |
| 대상 ShipProjectileAnchorCompo | Hit Point | 선체 명중 기준점 |
| 동일 컴포넌트 | Water Impact Point | 기본 물 착탄 기준점 |

Fire Points가 여러 개라고 한 번에 여러 발 발사하는 것은 아닙니다. 현재 구현은 유효한 지점을 순환하며 발사 위치를 선택합니다. 일제사격·다중탄 기능은 별도 흐름을 확인해야 합니다.

## 공격속도와 공격 간격

최종 간격은 `Attack Cooldown / FinalAttackSpeed`입니다. 기본 공격속도·함대 강화·지휘 버프가 최종 속도를 구성합니다. 공격속도 상승 때 Animator 속도도 맞추는 구조이므로 Animation 클립을 단순히 짧게 만들기 전에 원하는 변경이 모션 속도인지 공격 빈도인지 구분하세요.

## 새 탄 제작

1. `Assets/SB/Prefabs/Projectiles/NormalProjectile.prefab` 또는 특수탄을 복제합니다.
2. SpriteRenderer 그림·크기·재질을 바꿉니다.
3. BaseProjectile의 Rotate Along Path, Rotation Offset을 확인합니다. 그림의 앞 방향이 다르면 Offset을 맞춥니다.
4. NormalProjectile의 Hit Effect Prefab/Water Splash Effect Prefab을 확인합니다.
5. Sorting 설정으로 선체·물기둥과 겹침을 맞춥니다.
6. 새 함선 공격 컴포넌트의 Projectile Prefab에 연결합니다.
7. 발사, 명중, 회피, 표적 사망, 전투 종료, 재사용을 확인합니다.

Flight Data는 함선의 공격 컴포넌트에 있으므로 탄의 Scale만 바꿔도 비행 속도는 바뀌지 않습니다. 작살의 경로는 ProjectilePathDisplay, 파쇄탄의 코팅은 CrusherStakeCoating과 전용 재질입니다.

## 애니메이션 복제·연결

1. 새 함선용 Controller와 Idle/Move/Attack/Dead 클립을 준비합니다.
2. Visual의 Animator에 새 Controller를 연결합니다. EntityAnimator의 Animator 참조도 같은 대상을 가리키는지 확인합니다.
3. 클립의 Sprite 키를 새 외형으로 교체합니다.
4. 공격 클립의 이벤트 목록에서 AttackStart와 AttackEnd를 유지합니다. 사망 클립의 Dead 이벤트도 확인합니다.
5. MOVE/ATTACK/DEAD 등 실제 기존 Controller의 파라미터와 상태 이름을 유지하거나 코드와 함께 변경합니다.
6. 공격 상태의 AttackSpeedMultiplier 설정을 확인합니다.
7. 장전 그림이 있으면 발사 이벤트 시점에 숨기고 다음 공격에서 복원하도록 트랙을 맞춥니다.

함선마다 이벤트 시간이 같아야 하는 것은 아닙니다. “총구 반동/장전 그림 숨김/탄 생성”이 같은 순간에 맞는지 확인하는 것이 중요합니다. 기존 시간 기록은 현재 Animation 창과 대조하세요.

## 사망과 침몰

Dead 상태는 EntityHealth의 사망, ShipDeadState, Animator와 이벤트가 연결됩니다. 선체 재질의 Sink Progress를 애니메이션하는 함선은 재질 참조와 트랙을 함께 보세요. Visual 위치·Scale을 직접 고친 뒤 애니메이션이 덮어쓰는 트랙이 있는지도 확인합니다.

## 자주 생기는 문제

- 반동만 보임: AttackStart 이벤트/EntityAnimatorTrigger/총구/탄 참조 확인.
- 발사는 되는데 피해 없음: 대상 생존 여부, ShipCombatStatCompo, 보호·회피 판정 확인.
- 탄이 중간에 사라짐: Life Time이 실제 비행보다 짧은지 확인.
- 원본 그림으로 복귀: 다른 상태 클립에 원본 Sprite 키가 남아 있는지 확인.
- 풀 재사용 시 장전 그림이 남음: Idle/Move/Attack 트랙과 재활성 초기화 확인.

최후 일제사격은 일반 발사 이벤트와 별도 제어이며 [10번](10_운송선_화물표시_패배연출.md)을 참고하세요.
