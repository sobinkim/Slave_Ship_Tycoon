# 스탯과 공격 대상 설정

## 기본 스탯과 최종 값

`StatSO`는 체력/공격력 같은 종류를 정의하고, 프리팹의 `ShipStatCompo`가 종류별 기본값을 가지고 실행 중 값을 관리합니다. `ShipCombatStatCompo`는 여기에 함대 강화·지휘 버프를 반영한 최종 전투 값을 계산합니다.

프리팹별 밸런스 조절은 ShipStatCompo의 **Stat Container → Stat Overrides**를 먼저 확인하세요. 공용 `Assets/SB/SO/CommonStat`의 StatSO 기본값을 바꾸면 그 값을 사용하는 다른 함선까지 영향을 받을 수 있습니다.

| 값 | 조절 위치 | 주의점 |
|---|---|---|
| 체력 | Health Stat Override | 운송 본선은 별도 패배 규칙 사용 |
| 공격력 | AttackDamage Stat Override | 강화 후 최종 피해량과 구분 |
| 공격속도 | AttackSpeed Stat Override | 초 단위가 아니라 속도 배율로 사용 |
| 자연회복 | HealthRecoveryPerSecond Override | 아군 회복 관리자와 연결 필요 |
| 고유 운 | ShipCombatStatCompo.Base Luck | 아군은 함대 운 강화가 더해짐 |
| 공격 간격 | 공격 컴포넌트 Attack Cooldown | 속도 스탯과 별도 |

예: 기본 피해 20, 함대 공격력 강화 25이면 `20 × (1+25/100)=25`입니다. 기본 공격속도 1, 함대 공속 20%, 지휘 공속 50%이면 `1×1.2×1.5=1.8`입니다. 기본 간격 1.8초라면 최종 간격은 1초가 됩니다. 두 공속 퍼센트는 단순히 70%로 합쳐 계산하지 않습니다.

## TargetSelector 설정

Target Rules 배열은 위에서 아래로 우선순위를 검사합니다. 각 규칙은 Line과 Role로 후보를 고릅니다. 선택 모드는 규칙 안에서 어떤 한 척을 택할지 정합니다.

| 필드 | 값 | 의미 |
|---|---|---|
| Line | Front/Middle/Back/Any | 논리 열 기준 |
| Role | None | 역할 제한 없이 검사 |
| Role | Tanker/Dealer 등 | 특정 역할 후보 |
| Selection Mode | FormationDistribution | 공격자 편성을 이용한 분산 선택 |
| Selection Mode | HighestCurrentHealth | 현재 체력 최고, 동률이면 가까운 함선 |

고체력 모드가 최대 체력이나 공격력을 비교하는 것은 아닙니다. 전열 우선 규칙이 있으면 후열의 체력이 더 높아도 유효한 전열 후보를 먼저 선택합니다.

모든 규칙에 맞는 적이 없으면 나머지 유효한 후보 전체에서 선택합니다. 특정 Role 규칙 하나만 넣어도 그 역할이 없을 때 공격을 완전히 멈추는 제한으로 사용되지는 않습니다. 아군과 적 모두 Front/Middle/Back 세 논리 열을 사용합니다. 양 팀의 Front/Back은 서로 반대 X 인덱스에 매핑됩니다.

## 설정 예시

일반 전열 공격: Front/None → Middle/None → Back/None.

후열 습격: Back/None → Middle/None → Front/None. 보호받는 적까지 직접 공격하려면 Ship의 **Can Target Protected Ships**도 별도로 켜야 합니다.

전열 고체력 파쇄: 위 전열 규칙 + HighestCurrentHealth. 역할 우선 공격이 필요하면 예를 들어 Front/Tanker → Front/None → Middle/None 순으로 명시합니다.

## 논리 열과 화면 위치

적은 열 0이 전열, 1이 중열, 2가 후열입니다. 아군은 열 2가 전열, 1이 중열, 0이 후열입니다. 양쪽의 전열은 상대를 바라보지만 X 인덱스가 반대입니다. 타겟 코드는 진영별로 열을 해석하며, Transform X 위치가 바뀌어도 SpawnSlot은 배열에서 지정한 값을 사용합니다.

## 지휘와 보호가 우선하는 조건

지휘 집중공격의 지정 열이 있으면 일반 타겟 규칙보다 먼저 확인합니다. 하지만 일반 함선은 보호받는 대상을 후보에서 제외합니다. Can Target Protected Ships를 켜면 직접 목표로 삼을 수 있지만, 보호의 피해 감소가 없어지지는 않습니다.

현재 공격 흐름은 확보한 타겟이 유효하면 유지합니다. 고체력 모드를 켰다고 비행 중 탄이나 매 프레임의 표적이 자동으로 현재 최고 체력 함선으로 바뀌는 것은 아닙니다. 사망·비활성·보호 변화·지휘 명령 등으로 재선택되는 흐름을 함께 보세요.

## 확인하기

역할과 체력이 다른 적을 두어 먼저 어느 열을 선택하는지 봅니다. 선택된 적을 처치하거나 비활성화해 다음 대상으로 넘어가는지 확인합니다. 같은 조건의 적 두 척으로 분산/고체력 모드의 차이를 보고, 방어 보호와 지휘 스킬이 있는 전투도 확인합니다.
