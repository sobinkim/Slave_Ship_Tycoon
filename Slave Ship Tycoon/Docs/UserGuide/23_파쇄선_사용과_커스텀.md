# 파쇄선 사용과 커스텀

## 주요 파일

- 함선: `Assets/SB/Prefabs/PlayerShips/CrusherShip.prefab`
- 데이터: `Assets/SB/Data/PlayerFleet/EscortShips/Escort_CrusherShip.asset`
- 말뚝 탄: `Assets/SB/Prefabs/Projectiles/CrusherStake.prefab`
- 탄 그림: `Assets/SB/Art/Sprites/Projectiles/CrusherStake_Short.png`
- 코팅: CrusherStakeCoating / `Assets/SB/Art/Shaders/CrusherStakeAura.shader`
- 재질: `Assets/SB/Art/Materials/Ships/CrusherStakeAura.mat`
- 기록: `Assets/SB/Docs/CrusherShip.md`

## 공격 대상

전열 → 중열 → 후열 순으로 검사하며 각 규칙 안에서 **현재 체력이 가장 높은 적**을 선택합니다. 동률이면 가까운 적을 선택합니다. TargetSelector의 Selection Mode=HighestCurrentHealth와 Target Rules를 함께 확인하세요.

파쇄선이라는 이름이나 Piercer Role이 광역/보호 무시 피해를 자동 구현하지 않습니다. 현재 보호 중인 함선 직접 타겟 허용은 별도 옵션이며 기존 파쇄선 설정과 원하는 설계를 구분합니다. 지휘 집중공격 명령도 일반 규칙보다 우선합니다.

## 장전과 비행

빈 발사대 선체에 Visual/LoadedStake를 붙이고 실제 비행탄과 같은 말뚝 그림을 사용합니다. AttackStart 순간 LoadedStake를 숨기고 실제 CrusherStake를 발사합니다. 장전탄은 기본 재질, 비행탄은 코팅 재질을 사용합니다.

함선 비율은 Visual Scale, 장전 말뚝 비율은 LoadedStake Scale, 실제 탄은 CrusherStake Scale로 조절합니다. 공격 클립이 위치/표시를 덮는지도 확인하세요.

## 코팅 시간과 모양

CrusherStakeCoating의 Projectile/Projectile Renderer를 연결하고 Delay Seconds/Duration Seconds를 설정합니다. 비행 경과 시간으로 탄마다 MaterialPropertyBlock의 Coating Progress를 전달합니다. 공용 재질 진행도를 직접 바꾸는 방식은 아닙니다.

현재 셰이더는 오른쪽 촉 쪽에서 왼쪽 고리 쪽으로 드러나는 코팅입니다. 컴포넌트 Tooltip의 방향 문구와 과거 기록이 다를 수 있으므로 실제 셰이더/그림 방향을 기준으로 확인하세요.

재질의 Aura Color, Rim Highlight, Edge/Glow Width, Glow/Shell Opacity, Hexagon Density/Line Width/Opacity, Pulse Amount/Speed로 색·두께·무늬를 조절합니다. Shield UV Center/Half Size로 효과 범위를 그림에 맞춥니다.

전체 텍스처 UV와 여백을 사용하는 효과이므로 새 탄 그림의 크기·여백이 바뀌면 UV 범위도 다시 맞춰야 합니다. 현재 탄을 SpriteAtlas에 패킹해도 동일하게 보일 것으로 가정하지 마세요.

## 명중 흔들림

CrusherStakeImpactShake의 Shake Distance Units/Duration Seconds가 말뚝 명중 요청을 만들고 CameraImpactShake가 재생합니다. 회피 물 착탄·취소까지 명중 흔들림으로 처리되는지 구분해서 확인합니다.

## 새 파쇄형 함선 양산

기존 파쇄선·함선 데이터·탄·필요한 재질/클립을 복제하고 고유 ID와 수치를 넣습니다. 장전탄/실제 탄의 이미지·총구·이벤트를 맞추고 카탈로그/모집에 등록합니다. 모양만 바꾸려면 공유 타겟 코드를 수정할 필요가 없습니다.

## 확인 목록

앞 열의 적과 뒤 열의 고체력 적, 같은 열의 체력 차이, 체력 동률, 보호 대상, 지휘 명령을 비교합니다. 발사 전 장전, 발사 후 숨김, 코팅 0→1, 반환 후 0 복원, 다음 공격 재장전도 확인합니다. 기존 검증 숫자를 새 복제 콘텐츠의 성공으로 대신하지 마세요.
