# 공용 글자 크기와 간격

2026-10-22 사용자 요청으로 현재 Toolkit UI에 적용한 정보 우선순위입니다. 색·폰트·메뉴 구조를 새로 만드는 작업이 아니라, 같은 역할을 같은 크기로 읽게 하는 기준입니다.

## 크기 기준

1080×1920 기준 PanelSettings의 UI 단위입니다. 출력 화면의 실제 픽셀 크기는 패널 스케일에 따라 달라집니다. 공용 토큰은 `Assets/SB/UI/Shared/Styles/HarborTheme.uss`의 `.harbor-root`에 있습니다.

| 역할 | 토큰 | 크기 | 사용 예 |
| --- | --- | --- | --- |
| 최종 성과 | `--ui-font-display` | 64px | 정산 최종 지급액 |
| 화면 제목 | `--ui-font-title` | 44px | 함대 정비, 지휘 스킬, 화물 적재, 함대 편성, 함선 합성, 모집 |
| 큰 섹션 제목 | `--ui-font-section` | 36px | 보유 함선 |
| 핵심 재화·수치 | `--ui-font-value` | 36px | 보유 재화, 강화 가격, 적재량·예상 수익, 지급 재화 |
| 항목명·중요 레벨 | `--ui-font-item` | 32px | 강화 이름/레벨, 화물 이름, 선택한 스킬 이름, 주요 메뉴 |
| 조작·본문 | `--ui-font-body` | 28px | 버튼, 강화 효과, 화물별 보상, 함선 보유 수량 |
| 설명·좁은 카드 이름 | `--ui-font-description` | 26px | 함선/스킬 설명, 단위 중량, 상태, 카드 이름 |
| 보조 안내 | `--ui-font-caption` | 22px | 길게 누르기, 적용 시점, 미장착 안내 |
| 좁은 전투 HUD | `--ui-font-compact` | 20px | 운송 구간·화물 개수·도착 예상 토글 |

동일 중요도라도 공간과 기능이 다른 전투 HUD에는 별도 크기를 허용합니다. 얇은 운송 HUD의 제목은 24px, 결과 배율·슬롯 연출과 화면 진입의 72px 경고/문구는 기존 연출 우선순위를 유지합니다. 화면 제목과 보조 안내를 같은 크기로 맞추지 않습니다. 숫자만 커지고 단위가 떨어져 읽히지 않도록 관련 문자열의 줄바꿈을 함께 확인합니다.

## 간격과 아이콘

- 공용 간격은 8 / 16 / 24 / 32 / 40px입니다. 관계가 가까운 이름·레벨·수치는 8~16px, 다른 정보 묶음은 24~32px로 구분합니다. 독립 화면의 바깥 여백은 32px, 최근 승인된 적재 화면의 36×40px 여백은 해당 화면에서 유지합니다.
- 반화면 메뉴의 제목 행은 72~80px, 독립 화면 제목 행은 96px를 사용합니다. 강화 행은 144px, 적재 행은 기존 승인된 216px로 유지합니다. 긴 목록은 자체 ScrollView에서 스크롤합니다.
- 옆에 놓인 재화 아이콘은 `align-items: center`와 고정 축소 방지로 숫자와 중앙을 맞춥니다. 텍스트 36px에는 Sprite 여백을 포함한 44~48px 프레임, 텍스트 26~28px에는 32px 프레임을 사용합니다. 프레임 수치보다 실제 그림의 보이는 높이를 Game 뷰에서 확인합니다.
- 진입 문구 옆 기존 아이콘은 96px 프레임과 16px 간격을 사용합니다. 함선 카드처럼 그림이 위에 놓인 썸네일은 별도의 큰 시각 정보이므로 옆줄 아이콘 규칙으로 축소하지 않습니다.
- 아이콘이 없는 스킬은 이름으로 대체하되 같은 버튼에 이름을 두 번 표시하지 않습니다. 아이콘이 연결되면 원래 아이콘과 하단 이름을 표시합니다.
- 함선 등급은 반복되는 등급명을 카드마다 쓰지 않고 등급 테두리색으로 먼저 구분합니다. 함선 이름과 보유/대기 수량을 카드의 핵심 텍스트로 남깁니다. 현재 등급색은 일반 회색, 고급 초록, 희귀 파랑, 영웅 보라, 전설 금색입니다.
- 적재 화면에서 제거한 제목/수익/목록 제목/하단의 구분선을 복원하지 않습니다. 화물 행 사이 선만 유지합니다.

## 적용 범위

- `Shared/Styles/HarborTheme.uss`: 공용 토큰, 제목/본문/버튼/안내, 반복 함선 카드.
- `InGame/InGameScreen.uss`: HUD 재화, 강화 레벨/가격, 스킬 상세/슬롯/목록, 하단 메뉴.
- `Cargo/CargoScreen.uss`: 적재 제목/수치/보상/단위 중량/안내 및 재화 아이콘.
- `Fleet/FleetScreen.uss`, `FleetMergeScreen.uss`: 편성·합성·보유 목록·설명.
- `Fleet/FleetMergeScreen.uxml`: 보유 함선 제목과 재료 제외 안내 분리.
- `Recruitment/RecruitmentScreen.uss`: 모집 제목/보유 재화/가격/안내 및 결과 버튼 높이.
- `InGame/InGameFeedback.uss`: 정산·스테이지 피드백의 제목/성과/분해 값/설명.
- `Shared/ScreenEntryTransition.uss`: 문구 옆 아이콘의 보이는 크기와 간격.
- `SeaCreatureTest/SeaCreatureTest.uss`: 별도 조우 UI도 동일 역할 토큰 사용.
- `InGame/CommanderToolkitController.cs`: 폰트 인라인 지정 대신 대체 아이콘/텍스트 클래스만 연결.
- `Fleet/FleetToolkitScreen.cs`: 대기 수량과 보유 수량을 한 줄씩 표시해 숫자가 혼자 줄바꿈되는 문제 방지.

씬·프리팹·PanelSettings·폰트 에셋과 Inspector 필드는 이번 변경에 포함하지 않았습니다. 가격·레벨·확률·지급 데이터도 UI에서 변경하지 않습니다. 이전 스타일과 두 표시 코드의 사본은 `QA/UITypography/Before/`에 있습니다.

## 확인

- Unity 컴파일 성공, 새 UXML/USS 파싱 경고 없음. 기존 `MerchantLedger needs an icon.` 오류는 별개로 남아 있습니다.
- 실제 메뉴 연결로 강화·스킬·함대·합성·모집·적재를 열어 확인했습니다. 540×960과 360×640에서 주요 메뉴의 제목/숫자/보조 안내와 스크롤, 고정 하단 버튼을 확인했습니다.
- 강화의 UI 표시만 `Lv. 99999` / `999.99T 골드`로 바꿔 확인했습니다. 가격 문자열의 자연 너비는 약 213 UI px, 실제 텍스트 영역은 약 221 UI px로 잘리지 않았습니다. 표시를 실제 값으로 복원했습니다.
- 정산·모집 11척 결과·운송 HUD는 표시용 데이터로 확인했습니다. 모집/합성/강화 구매·보상 지급·시세 판정 이벤트는 발생시키지 않았습니다. 조우 UI는 SampleScene 안의 일시적인 표시 트리로 확인하고 제거했습니다.
- 진입 연출은 보유한 실제 프리셋을 복사해 표시 유지 시간만 임시로 늘린 뒤 Play/Cancel로 확인했습니다. HUD가 숨겨지고 복구되며, 시간 배율은 실행 전후 1이었습니다. 저장된 프리셋 시간은 바꾸지 않았습니다.
- 캡처는 `Assets/QA/UITypography/`에 있습니다. 기기 터치·Safe Area·다른 종횡비 및 전체 전투/정산 흐름은 이번 글자 크기 확인 범위에 포함하지 않았습니다.
