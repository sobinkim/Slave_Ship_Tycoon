# 전체 UI 스타일 정리 — 2026-10-16

## 적용 범위

- 공용 `HarborTheme.uss`, `HarborMaterials.uss`, `HarborRuntimeTheme.tss`.
- 함대, 합성, 모집, 적재, 인게임 HUD·정산, 해양 생물 테스트 UI의 USS. 스타일 파일 총 10개.
- HUD의 어두운 팔레트를 공용 테마로 이동. 목재·금속 장식 배경과 컨트롤의 둥근 모서리를 제거하고, 안내·수익 내역의 중복 박스를 구분선으로 정리.
- 전체 화면 결과창·선택창은 불투명 배경. 작은 화물 상세창은 기존 주변 화면의 어두운 오버레이를 유지.
- UXML, C#, 씬·프리팹·데이터·Inspector 값은 수정하지 않음. 기존 아이콘·텍스처 자산은 보존.

## 검증

- Unity Editor에서 10개 USS/TSS 재임포트: 오류 0, 경고 0. 현재 C# 컴파일 실패 없음.
- 기존 위치·크기·여백·Flex·표시 여부 선언과 스타일 토큰 참조를 비교·확인.
- 실제 SampleScene의 HUD, 지휘 스킬, 함대, 합성, 모집, 적재, 화물 상세·선택창을 확인.
- 모집 11척 결과·합성 결과·정산은 기존 함선 데이터와 일시적인 표시용 결과로 미리보기. 실제 모집·합성·정산 지급을 실행하지 않음. 미리보기 전후 보유 재화 `1000,100,1000` 동일.
- 6개 활성 화면에서 버튼·공용 패널의 모서리 반경과 장식 텍스처가 0임을 확인. 함선·재화·화물 그림과 등급·선택 표시는 유지.
- 함대 아군/적군 영역은 각각 493×650px. 모집 하단 영역과 기존 카드·슬롯 배치는 유지.
- 540×960 캡처 11개 저장. 해양 생물 테스트 UI는 임포트만 확인했으며 다른 화면 비율·Safe Area·실기기 터치는 확인하지 않음.
- 기존 `MerchantLedger needs an icon.` 오류는 남아 있음. UI 스타일 임포트 오류와 구분.
- 확인 종료 시 Play Mode 종료, TimeScale 1, 씬 미변경 상태로 복구. 임시 캡처 에셋은 정리.
